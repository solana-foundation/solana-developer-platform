---
module: earn
title: Treasury
description: Put your organization's idle stablecoins to work through the same Earn API and operation flow.
---

Treasury uses the same Earn API as Embedded Yield, with no separate yield
endpoints. Your organization's wallet is the `ownerAddress`: prepare a deposit,
sign it with that wallet, submit it and poll the operation, as in the
[quickstart](/docs/earn/quickstart).

If the treasury wallet is an SDP custody wallet, pass its `walletId` instead.
SDP then requests the signature from the wallet's custody provider and keeps
its signing and fee policies; signing progress survives the request and browser
session.
