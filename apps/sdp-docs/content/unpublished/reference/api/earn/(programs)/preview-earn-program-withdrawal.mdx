<ApiOperation>

<ApiEndpoint method="POST" path="/v1/earn/programs/{programId}/withdrawal-preview" />

Omit amountUsd to read liquidity only, or include it to preview a payout. Wallet-scoped API keys cannot use this provider account; use an organization-wide key.

Requires an [API key](/docs/developing-with-sdp/authentication) with the `earn.read` action.

## Path parameters

- **`programId`** · `string` · required · min length 1

## Headers

- **`x-project-id`** · `string` · min length 1 · example `prj_example`

  Required for dashboard sessions. API keys use their assigned project.

## Request body

`application/json` · required

- **`amountUsd`** · `string` · pattern `^(?!0+(?:\.0+)?$)\d+(?:\.\d{1,6})?$`

- **`token`** · `string` · required · one of `usdc`, `usdt`

      - **`totalUsdAfterWithdrawal`** · `string` · required

      - **`processingEstimate`** · `object`

        - **`basis`** · `string` · required · one of `elapsed_seconds`, `banking_days`

        - **`typicalMinDuration`** · `string` · required

        - **`typicalMaxDuration`** · `string` · required

  - **`meta`** · `object` · required

    Response metadata.

      Request identifier for tracing.
