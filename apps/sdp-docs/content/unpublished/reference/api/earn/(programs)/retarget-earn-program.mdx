<ApiOperation>

<ApiEndpoint method="PUT" path="/v1/earn/programs/{programId}" />

Each supplied token group currently requires one allocation at 100 percent; omitted token groups keep their existing allocation. The program label is unchanged. A new intentional operation needs a new Idempotency-Key, even with identical terms. Retrying an uncertain operation must reuse its key and exact payload. An idempotency key is optional; send Idempotency-Key or body requestId (UUIDv4), never both.

Requires an [API key](/docs/developing-with-sdp/authentication) with the `earn.manage` action.

## Path parameters

- **`programId`** · `string` · required · min length 1

## Headers

- **`x-project-id`** · `string` · min length 1 · example `prj_example`

  Required for dashboard sessions. API keys use their assigned project.

- **`Idempotency-Key`** · `string` · pattern `^[\x20-\x7e]{1,255}$` · example `idempotency_example_12345`

  Idempotency key for safely retrying mutating requests. 1-255 printable ASCII characters; echoed back on the response.

## Request body

`application/json` · required

- **`allocations`** · `object` · required

  - **`usdc`** · `object[]` · min items 1 · max items 1

    - **`yieldSourceId`** · `string` · required · min length 1

    - **`pct`** · `number` · required · greater than 0 · max 100

  - **`usdt`** · `object[]` · min items 1 · max items 1

    - **`yieldSourceId`** · `string` · required · min length 1

    - **`pct`** · `number` · required · greater than 0 · max 100

- **`requestId`** · `string` · format `uuid`

## Responses

- **`200`** Result

  - **`data`** · `object` · required

    - **`program`** · `object` · required

      - **`id`** · `string` · required · example `earn_provider_wallet_example`

        SDP program ID used by the programs endpoints.

      - **`provider`** · `string` · required · example `perena`

      - **`label`** · `string | null` · required

      - **`createdAt`** · `string` · required

      - **`wallet`** · `object` · required

        - **`providerWalletRef`** · `string` · required

        - **`status`** · `string` · required · one of `creating`, `ready`, `busy`, `failed`

        - **`activity`** · `string` · one of `withdrawing`, `rebalancing`

        - **`providerStatus`** · `string`

        - **`solanaDepositAddress`** · `string`

          Provider wallet's Solana funding address, when available.

        - **`balance`** · `object` · required

          - **`totalUsd`** · `string` · required · example `1000.00`

            Live total provider balance in USD.

          - **`withdrawableUsd`** · `string` · required · example `980.00`

            USD value the provider currently permits to withdraw.

          - **`reservedUsd`** · `string` · required · example `20.00`

            USD value currently reserved by the provider.

          - **`earnedUsd`** · `string` · required · example `12.34`

            Provider-reported cumulative yield in USD.

        - **`positions`** · `object[]` · required

          - **`kind`** · `string` · required · one of `yield_source`, `cash`, `bridge`, `external_payout`, `unknown`

          - **`label`** · `string` · required

          - **`valueUsd`** · `string` · required

          - **`pct`** · `number`

          - **`yieldSourceId`** · `string`

          - **`token`** · `string` · one of `usdc`, `usdt` · example `usdc`

        - **`allocations`** · `object` · required

          Live provider allocations. Response weights use basis points; requests use pct.

          - **`usdc`** · `object[]`

            - **`yieldSourceId`** · `string` · required

            - **`weightBps`** · `number` · required · example `10000`

              Allocation weight in basis points; 10000 means 100 percent.

          - **`usdt`** · `object[]`

            - **`yieldSourceId`** · `string` · required

            - **`weightBps`** · `number` · required · example `10000`

              Allocation weight in basis points; 10000 means 100 percent.

      - **`yield`** · `object`

        Live yield breakdown. Absent if the yield read fails; wallet balances remain live.

        - **`currentApy`** · `string` · example `0.062`

          Blended APY as a decimal ratio; 0.062 means 6.2 percent.

        - **`earnedUsd`** · `string` · required

        - **`annualizedUsd`** · `string`

        - **`positions`** · `object[]` · required

          - **`yieldSourceId`** · `string` · required

          - **`name`** · `string` · required

          - **`apy`** · `string` · required

          - **`pct`** · `number` · required
