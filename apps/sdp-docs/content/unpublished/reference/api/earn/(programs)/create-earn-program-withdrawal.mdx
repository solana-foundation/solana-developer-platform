<ApiEndpoint method="POST" path="/v1/earn/programs/{programId}/withdrawals" />

Wallet-scoped API keys are refused. Returns 201 for an accepted request and 200 for a matching replay; reuse the original key and payload after an uncertain response. Track the live provider withdrawal outcome. A new intentional operation needs a new Idempotency-Key, even with identical terms. Retrying an uncertain operation must reuse its key and exact payload. Supply exactly one key through Idempotency-Key or body requestId (UUIDv4).

Requires an [API key](/docs/developing-with-sdp/authentication) with the `earn.execute` action.

## Path parameters

- **`programId`** · `string` · required · min length 1

## Headers

- **`x-project-id`** · `string` · min length 1 · example `prj_example`

  Required for dashboard sessions. API keys use their assigned project.

- **`Idempotency-Key`** · `string` · pattern `^[\x20-\x7e]{1,255}$` · example `idempotency_example_12345`

  Idempotency key for safely retrying mutating requests. 1-255 printable ASCII characters; echoed back on the response.

## Request body

`application/json` · required

- **`amountUsd`** · `string` · required · pattern `^(?!0+(?:\.0+)?$)\d+(?:\.\d{1,6})?$`

- **`token`** · `string` · required · one of `usdc`, `usdt`

- **`requestId`** · `string` · format `uuid`

- **`destinationAddress`** · `string` · required

## Example request

```bash tab="cURL"
curl -X POST 'https://api.solana.com/v1/earn/programs/program_example/withdrawals' \
  -H "Authorization: Bearer $SDP_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d '{
    "amountUsd": "example",
    "token": "usdc",
    "destinationAddress": "11111111111111111111111111111111"
  }'
```
