<ApiOperation>

<ApiEndpoint method="POST" path="/v1/earn/vault-deposit-previews" />

Use it when the strategy's `depositSlippage.quoteRequired` is true, then derive `minSharesOut` from `sharesOut` minus the chosen tolerance. Read-only, no idempotency key, and 501 when the provider cannot quote deposits. Takes the deposit's own gates in the caller's project environment, provider entitlement included.

Requires an [API key](/docs/developing-with-sdp/authentication) with the `earn.read` action.

## Headers

- **`x-project-id`** · `string` · min length 1 · example `prj_example`

  Required for dashboard sessions. API keys use their assigned project.

## Request body

`application/json` · required

Quote one direct vault deposit against the provider's live accounting. Read-only: nothing is built and nothing is persisted.

- **`strategyId`** · `string` · required · min length 1 · example `earn_strategy_example`

- **`amount`** · `string` · required · max length 128 · pattern `^(?=.*[1-9])\d+(\.\d+)?$` · example `25`

  Deposit amount in the vault token's units.

## Responses

- **`200`** Live deposit quote

  - **`data`** · `object` · required

    - **`strategyId`** · `string` · required · example `earn_strategy_example`

    - **`sharesOut`** · `string` · required · max length 128 · pattern `^(?=.*[1-9])\d+(\.\d+)?$` · example `24.98`

      Shares the deposit would mint at the live rate. Derive `minSharesOut` from this value minus the chosen tolerance, quantized to `shareDecimals`.

    - **`shareDecimals`** · `integer` · required · example `6`

      The share mint's decimals, which the floor must be quantized to.

    - **`blockingIssues`** · `object[]` · required

      Conditions the provider reports would block this deposit; empty when none.

      - **`code`** · `string` · required · example `SHARE_LOCKED`

      - **`message`** · `string` · required

    - **`feeSponsored`** · `boolean` · required

      Whether SDP's treasury vault flow would use its configured paymaster on this cluster. Embedded Yield partners sponsor their external-wallet flow separately by passing `feePayer` to the transaction build.

  - **`meta`** · `object` · required

    Response metadata.

    - **`requestId`** · `string` · required · min length 1 · example `req_example`

      Request identifier for tracing.

    - **`timestamp`** · `string` · required · format `date-time` · example `2025-01-01T00:00:00.000Z`

      ISO 8601 timestamp.

## Example request

```bash tab="cURL"
curl -X POST 'https://api.solana.com/v1/earn/vault-deposit-previews' \
  -H "Authorization: Bearer $SDP_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "strategyId": "earn_strategy_example",
    "amount": "25"
  }'
```
