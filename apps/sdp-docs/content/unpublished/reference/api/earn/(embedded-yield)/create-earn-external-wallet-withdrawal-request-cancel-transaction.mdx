<ApiEndpoint method="POST" path="/v1/earn/external-wallet/withdrawal-request-cancel-transactions" />

A solver request becomes cancellable only at expiredCancelable because fulfilment is permitted through its deadline. A cancelable operator redemption may be revoked while pending; cancellation leaves the owner with the intermediate token rather than recreating the original shares.

Requires an [API key](/docs/developing-with-sdp/authentication) with the `earn.manage` action.

## Headers

- **`x-project-id`** · `string` · min length 1 · example `prj_example`

  Required for dashboard sessions. API keys use their assigned project.

## Request body

`application/json` · required

Build the owner-signed recovery transaction. Solver requests become cancellable at expiredCancelable; a cancelable operator redemption may be revoked while pending.

- **`withdrawalRequestId`** · `string` · required · min length 1 · max length 128 · example `earn_vault_withdrawal_request_example`

- **`feePayer`** · `string` · min length 32 · max length 44 · pattern `^[1-9A-HJ-NP-Za-km-z]{32,44}$` · example `3nMFwZXwY1s1M5s8vYAHqd4wGs4iSxXE4LRoUMMYqEgF`

  Authenticated builds only: pay for this transaction from your own wallet instead of the customer's. The named address becomes the transaction's fee payer. It pays the network fee, funds any share-account rent, and must sign alongside the owner. Co-sign server-side with the fee payer's key before submitting. Simulation refuses the build with a 400 naming the fee payer when it cannot pay. Sending the owner's own address uses the default: the owner pays and signs alone.

- **`200`** Unsigned asynchronous-withdrawal cancellation transaction

      Any of:

      - **One unsigned transaction SDP built for an external wallet to sign.**

        - **`transactionId`** · `string` · required · example `earn_external_wallet_transaction_example`

        - **`transaction`** · `string` · required

          Base64 wire bytes of the unsigned transaction. Add every required signature without changing the message, then submit through SDP. The blockhash bounds when the network can first accept it; retain the original signed bytes for recovery.

        - **`lastValidBlockHeight`** · `string` · required · example `361186610`

          Last block height at which the network can first accept this transaction. This is a block height, not a slot or timestamp.

        - **`sponsored`** · `boolean` · required · example `false`

          Whether SDP supplied and signed the fee payer. A partner-controlled feePayer leaves this false.

        - **`ownerAddress`** · `string` · required · min length 32 · max length 44 · pattern `^[1-9A-HJ-NP-Za-km-z]{32,44}$` · example `9WzDXwBbmkg8ZTbNMqUxvQRAyrZzDsGYdLVL9zYtAWWM`

          The external wallet: the customer's own Solana address. It signs and owns the shares; SDP holds no key for it. It also pays the network fee unless an authenticated build names a `feePayer`. The pattern is necessary but not sufficient — the string must additionally decode to a 32-byte public key, which no pattern can express, so a well-shaped base58 string that does not decode still answers 400.

        - **`feePayer`** · `string` · example `3nMFwZXwY1s1M5s8vYAHqd4wGs4iSxXE4LRoUMMYqEgF`

          Echo of an authenticated build request's `feePayer`. Present, this transaction requires the fee payer's signature IN ADDITION to the owner's — co-sign server-side before submitting; the submit refuses a missing or invalid fee-payer signature. Absent, the owner signs alone and pays the fee.

        - **`provider`** · `string` · required · example `kamino`
