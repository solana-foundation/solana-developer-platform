<ApiOperation>

<ApiEndpoint method="POST" path="/v1/earn/external-wallet/withdrawal-previews" />

When the strategy's `withdrawalSlippage` is not null, set `minAmountOut` from this quote: take your tolerance off `assetsOut`, rounded down to `assetDecimals`. The preview is read-only, takes no Idempotency-Key, and still works after a strategy is deprecated or its provider stops taking deposits. It does not check the wallet's balance, so keep `shares` within the position's `withdrawableShares`. It returns 501 when the provider cannot quote withdrawals.

Requires an [API key](/docs/developing-with-sdp/authentication) with the `earn.read` action.

## Headers

- **`x-project-id`** · `string` · min length 1 · example `prj_example`

  Required for dashboard sessions. API keys use their assigned project.

## Request body

`application/json` · required

Quote one withdrawal from a position against the strategy's live accounting. Read-only: nothing is built or saved.

- **`positionId`** · `string` · required · min length 1 · max length 128 · example `earn_position_2f8b6b04-7147-487e-b760-b1caa4fbcb8b`

  The position's ID, from the positions list or the deposit submit response.

- **`shares`** · `string` · required · max length 128 · pattern `^(?=.*[1-9])\d+(\.\d+)?$` · example `10`

  Shares to withdraw, as a decimal string in share units. Keep it within the position's `withdrawableShares`: the preview does not check the balance.

## Responses

- **`200`** Live withdrawal quote

  - **`data`** · `object` · required

    - **`positionId`** · `string` · required · min length 1 · max length 128 · example `earn_position_2f8b6b04-7147-487e-b760-b1caa4fbcb8b`

      The position's ID, from the positions list or the deposit submit response.

    - **`assetsOut`** · `string` · required · max length 128 · pattern `^(?=.*[1-9])\d+(\.\d+)?$` · example `25.02`

      What redeeming the shares would pay at the live rate, decimal string in the deposit token's units. A truthful `minAmountOut` floor is derived from this figure.

    - **`assetDecimals`** · `integer` · required · example `6`

      The deposit token's decimals, which define the scale used to quantize a floor.

    - **`blockingIssues`** · `object[]` · required

      Conditions the provider reports would block this withdrawal; empty when none.

      - **`code`** · `string` · required · example `SHARE_LOCKED`

      - **`message`** · `string` · required

  - **`meta`** · `object` · required

    Response metadata.

    - **`requestId`** · `string` · required · min length 1 · example `req_example`

      Request identifier for tracing.

    - **`timestamp`** · `string` · required · format `date-time` · example `2025-01-01T00:00:00.000Z`

      ISO 8601 timestamp.
