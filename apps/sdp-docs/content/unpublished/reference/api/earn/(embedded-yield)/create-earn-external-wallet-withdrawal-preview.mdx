<ApiOperation>

<ApiEndpoint method="POST" path="/v1/earn/external-wallet/withdrawal-previews" />

Read-only, no idempotency key, and it takes the exit's own gates: a delisted strategy or a provider disabled for new deposits stays quotable. The request names its tenant position. POST because the parameters are a body; 501 when the provider cannot quote exits.

Requires an [API key](/docs/developing-with-sdp/authentication) with the `earn.read` action.

## Headers

- **`x-project-id`** · `string` · min length 1 · example `prj_example`

  Required for dashboard sessions. API keys use their assigned project.

## Request body

`application/json` · required

Quote one exit of the caller's tenant position against the vault's live accounting. Read-only: nothing is built and nothing is persisted.

- **`positionId`** · `string` · required · min length 1 · max length 128 · example `earn_position_example`

  The caller's tenant-scoped external-wallet position.

- **`shares`** · `string` · required · max length 128 · pattern `^(?=.*[1-9])\d+(\.\d+)?$` · example `10`

  Shares the exit would redeem, decimal string in share units.

## Responses

- **`200`** Live exit quote

  - **`data`** · `object` · required

    - **`positionId`** · `string` · required · min length 1 · max length 128 · example `earn_position_example`

      The caller's tenant-scoped external-wallet position.

    - **`assetsOut`** · `string` · required · max length 128 · pattern `^(?=.*[1-9])\d+(\.\d+)?$` · example `25.02`

      What redeeming the shares would pay at the live rate, decimal string in the deposit token's units. A truthful `minAmountOut` floor is derived from this figure.

    - **`assetDecimals`** · `integer` · required · example `6`

      The deposit token's decimals, which define the scale used to quantize a floor.

    - **`blockingIssues`** · `object[]` · required

      Conditions the provider reports would block this exit; empty when none.

      - **`code`** · `string` · required · example `SHARE_LOCKED`

      - **`message`** · `string` · required

  - **`meta`** · `object` · required

    Response metadata.

    - **`requestId`** · `string` · required · min length 1 · example `req_example`

      Request identifier for tracing.

    - **`timestamp`** · `string` · required · format `date-time` · example `2025-01-01T00:00:00.000Z`

      ISO 8601 timestamp.

- **`400`** Bad Request

  - **`error`** · `object` · required

    Standard error payload.

    - **`code`** · `string` · required

      Machine-readable error code.

    - **`message`** · `string` · required

      - **`*`** · `any`

  - **`meta`** · `object`

- **`401`** Unauthorized

  Same fields as `400`.

- **`403`** Forbidden. Requires the `earn.read` action: an API key must hold it (a module's `manage` or `execute` also covers its `read`), and a signed-in member's organization role must include it. ## Example request

```bash tab="cURL"
curl -X POST 'https://api.solana.com/v1/earn/external-wallet/withdrawal-previews' \
  -H "Authorization: Bearer $SDP_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "positionId": "earn_position_example",
    "shares": "10"
  }'
```
