<ApiOperation>

<ApiEndpoint method="GET" path="/v1/earn/external-wallet/withdrawal-requests" />

Use settled=false on startup and after reconnecting to restore every request that still needs fulfilment, classification or cancellation. Page until hasMore is false.

Requires an [API key](/docs/developing-with-sdp/authentication) with the `earn.read` action.

## Query parameters

- **`ownerAddress`** · `string` · required

- **`limit`** · `integer` · min 1 · max 100 · default `20`

- **`before`** · `string` · min length 1

- **`status`** · `string` · one of `creating`, `pending`, `fulfillable`, `expiredCancelable`, `cancelling`, `closedOrUnknown`, `fulfilled`, `cancelled`, `failed`

- **`settled`** · `string` · one of `true`, `false`

## Headers

- **`x-project-id`** · `string` · min length 1 · example `prj_example`

  Required for dashboard sessions. API keys use their assigned project.

          The external wallet: the customer's own Solana address. It signs and owns the shares; SDP holds no key for it. It also pays the network fee unless an authenticated build names a `feePayer`. The pattern is necessary but not sufficient — the string must additionally decode to a 32-byte public key, which no pattern can express, so a well-shaped base58 string that does not decode still answers 400.

          Base58 Solana mint address.

        - **`shares`** · `string` · required · max length 128 · pattern `^(?=.*[1-9])\d+(\.\d+)?$` · example `25`

          Positive decimal string with at least one non-zero digit; never a float.

        - **`quotedAssets`** · `string` · required · max length 128 · pattern `^(?=.*[1-9])\d+(\.\d+)?$` · example `25`

          Expected payout at request creation, in asset units. Not a settled amount.

        - **`assetDecimals`** · `integer` · required · min 0 · max 38

        - **`creationSignature`** · `string | null` · required

        - **`cancelSignature`** · `string | null` · required

          Cancellation transaction, when recovery was submitted.

        - **`closingSignature`** · `string | null` · required

          Provider-authenticated fulfillment or cancellation transaction, when known.

        - **`assetsPaid`** · `string | null` · required · max length 128 · pattern `^(?=.*[1-9])\d+(\.\d+)?$` · example `25`

          Observed fulfillment payout in asset units, or null before it is known.

        - **`failureReason`** · `string | null` · required

        - **`fulfilledAt`** · `string | null` · required · format `date-time` · example `2025-01-01T00:00:00.000Z`

          ISO 8601 timestamp.

          ISO 8601 timestamp.
