<ApiEndpoint method="POST" path="/v1/earn/provider-actions/external/preparations" />

Reuse the same key and payload after uncertain outcomes. Builds return a base64 VersionedTransaction requiring the owner and optional fee payer signatures. Submit the exact message with all existing protocol signatures preserved. Preparation must be finalized or not_required before a sponsored first mint. Cancellation uses the recorded original order and cancels the provider's aggregate pending standard redemption for that wallet and vault; finalization requires verified share return. A confirmed source transaction alone never proves fulfillment.

Requires an [API key](/docs/developing-with-sdp/authentication) with the `earn.execute` action.

## Headers

- **`x-project-id`** · `string` · min length 1 · example `prj_example`

  Required for dashboard sessions. API keys use their assigned project.

- **`Idempotency-Key`** · `string` · required · pattern `^[\x20-\x7e]{1,255}$` · example `idempotency_example_12345`

  Idempotency key for safely retrying mutating requests. 1-255 printable ASCII characters; echoed back on the response.

## Request body

`application/json` · required

- **`actionId`** · `string` · required · min length 1 · max length 255

- **`signedTransaction`** · `string` · required · min length 1 · max length 4096

## Example request

```bash tab="cURL"
IDEMPOTENCY_KEY=$(uuidgen)
curl -X POST 'https://api.solana.com/v1/earn/provider-actions/external/preparations' \
  -H "Authorization: Bearer $SDP_API_KEY" \
  -H "Idempotency-Key: $IDEMPOTENCY_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "actionId": "action_example",
    "signedTransaction": "example"
  }'
```

```ts tab="TypeScript"
// Reuse this key when you retry this request.
const idempotencyKey = crypto.randomUUID();
const res = await fetch("https://api.solana.com/v1/earn/provider-actions/external/preparations", {
  method: "POST",
  headers: {

    "Content-Type": "application/json"

    "signedTransaction": "example"

```
