<ApiOperation>

<ApiEndpoint method="GET" path="/v1/earn/provider-actions/{actionId}" />

Scoped to the authenticated project and environment. Preparation is not_required when its share account already exists, otherwise finalizes at Solana finality; cancellation awaits a verified share return. No additional claim transaction is required.

Requires an [API key](/docs/developing-with-sdp/authentication) with the `earn.read` action.

## Path parameters

- **`actionId`** · `string` · required · min length 1 · max length 255

## Headers

- **`x-project-id`** · `string` · min length 1 · example `prj_example`

  Required for dashboard sessions. API keys use their assigned project.

## Responses

- **`200`** Provider action

  - **`data`** · `object` · required

    - **`action`** · `object` · required

      - **`actionId`** · `string` · required

      - **`action`** · `string` · required · one of `preparation`, `cancellation`

      - **`status`** · `string` · required · one of `preparing`, `not_required`, `prepared`, `requested`, `submitted`, `confirmed`, `awaiting_delivery`, `finalized`, `failed`

      - **`provider`** · `string` · required

      - **`providerReference`** · `string` · required

      - **`ownerAddress`** · `string` · required

      - **`feePayer`** · `string | null` · required

      - **`parentMovementId`** · `string | null` · required

      - **`signature`** · `string | null` · required

      - **`deliverySignature`** · `string | null` · required

      - **`lastValidBlockHeight`** · `string | null` · required

      - **`error`** · `string | null` · required

      - **`createdAt`** · `string` · required

      - **`transaction`** · `string | null` · required

  - **`meta`** · `object` · required

    Response metadata.

    - **`requestId`** · `string` · required · min length 1 · example `req_example`

      Request identifier for tracing.

    - **`timestamp`** · `string` · required · format `date-time` · example `2025-01-01T00:00:00.000Z`

      ISO 8601 timestamp.

- **`400`** Bad Request

  - **`error`** · `object` · required

    Standard error payload.

    - **`code`** · `string` · required

      Machine-readable error code.

    - **`message`** · `string` · required

      Human-readable error message.

    - **`details`** · `object`

      Optional error details for debugging.

      - **`*`** · `any`

  - **`meta`** · `object`

    - **`requestId`** · `string` · min length 1 · example `req_example`

      Request identifier for tracing.

- **`401`** Unauthorized

  Same fields as `400`.

- **`403`** Forbidden. Requires the `earn.read` action: an API key must hold it (a module's `manage` or `execute` also covers its `read`), and a signed-in member's organization role must include it. Without it the error is INSUFFICIENT_PERMISSIONS and `error.details.action` names the action. Any other 403 names its own reason.

  Same fields as `400`.

- **`404`** Not Found

  Same fields as `400`.

- **`409`** Conflict

  Same fields as `400`.

- **`422`** Unprocessable Entity

  Same fields as `400`.

- **`429`** Too Many Requests

  Same fields as `400`.

- **`500`** Internal Server Error

  Same fields as `400`.

- **`503`** Service Unavailable

  Same fields as `400`.
