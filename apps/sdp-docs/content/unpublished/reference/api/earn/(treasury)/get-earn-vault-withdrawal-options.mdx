<ApiOperation>

<ApiEndpoint method="POST" path="/v1/earn/vault-withdrawal-options" />

Call when starting a withdrawal and let the customer choose when several routes are available. Do not infer availability from liquidityTerm.

Requires an [API key](/docs/developing-with-sdp/authentication) with the `earn.read` action.

## Headers

- **`x-project-id`** · `string` · min length 1 · example `prj_example`

  Required for dashboard sessions. API keys use their assigned project.

## Request body

`application/json` · required

- **`positionId`** · `string` · required · min length 1 · max length 128

## Responses

- **`200`** Result

  - **`data`** · `object` · required

    - **`positionId`** · `string` · required

    - **`instant`** · `boolean` · required

      Whether an atomic withdrawal is independently available.

    - **`providerOrder`** · `boolean` · required

      Whether a provider-managed delayed order is independently available.

    - **`queued`** · `boolean` · required

      Whether the cancellable on-chain queue is currently available. Never infer this from liquidityTerm alone.

    - **`withdrawAuthority`** · `string | null` · required

      The vault's configured withdrawal authority, or null without a queue.

    - **`queueState`** · `string | null` · required

      The provider queue account, or null without a queue.

    - **`queueAsset`** · `object | null` · required

      Live asset-specific queue limits. Null when this asset has no queue configuration.

      - **`assetMint`** · `string` · required · min length 32 · max length 44 · pattern `^[1-9A-HJ-NP-Za-km-z]{32,44}$` · example `2b1kV6DkPAnxd5ixfnxCpjxmKwqjjaYmCZfHsFu24GXo`

        Base58 Solana mint address.

      - **`allowWithdrawals`** · `boolean` · required

        Whether this asset's queue currently accepts new requests.

      - **`secondsToMaturity`** · `integer` · required · min 0 · example `86400`

        Delay after request creation before a solver may fulfil it.

      - **`minimumSecondsToDeadline`** · `integer` · required · min 0 · example `3600`

        Shortest solver window accepted after maturity.

      - **`maximumSecondsToDeadline`** · `integer` · required · greater than 0 · max 7776000 · example `7776000`

        Longest solver window accepted after maturity.

      - **`minimumDiscountBps`** · `integer` · required · min 0 · max 10000 · example `0`

      - **`maximumDiscountBps`** · `integer` · required · min 0 · max 10000 · example `500`

      - **`minimumShares`** · `string` · required · max length 128 · pattern `^(?=.*[1-9])\d+(\.\d+)?$` · example `1`

        Smallest request accepted by the queue, in share units.

      - **`shareDecimals`** · `integer` · required · min 0 · max 38 · example `6`

    - **`parRedemption`** · `object | null` · required

      Live issuer/operator redemption terms. Null when this strategy has no operator-completed par route.

      - **`intermediateMint`** · `string` · required · min length 32 · max length 44 · pattern `^[1-9A-HJ-NP-Za-km-z]{32,44}$` · example `2b1kV6DkPAnxd5ixfnxCpjxmKwqjjaYmCZfHsFu24GXo`

        Token created or delegated by the request transaction and later burned by the operator.

      - **`assetMint`** · `string` · required · min length 32 · max length 44 · pattern `^[1-9A-HJ-NP-Za-km-z]{32,44}$` · example `2b1kV6DkPAnxd5ixfnxCpjxmKwqjjaYmCZfHsFu24GXo`

        Token the operator pays when the redemption completes.

      - **`minimumShares`** · `string | null` · required · max length 128 · pattern `^(?=.*[1-9])\d+(\.\d+)?$` · example `1`

        Smallest share-sourced operator-redemption request, in position-share units. Null while the provider's rate is unavailable, which also blocks share-sourced requests.

      - **`minimumIntermediateAmount`** · `string` · required · max length 128 · pattern `^(?=.*[1-9])\d+(\.\d+)?$` · example `0.000001`

        Smallest request over intermediate the owner already holds, in intermediate-token units.

      - **`shareDecimals`** · `integer` · required · min 0 · max 38 · example `6`

      - **`assetDecimals`** · `integer` · required · min 0 · max 38 · example `6`

      - **`cancelable`** · `boolean` · required

        Whether the owner may revoke an open request before the operator completes it.

      - **`operatorSettled`** · `boolean` · required · always `true`

        Always true: a provider operator must complete the eventual asset payout.

  - **`meta`** · `object` · required

    Response metadata.

    - **`requestId`** · `string` · required · min length 1 · example `req_example`

      Request identifier for tracing.

    - **`timestamp`** · `string` · required · format `date-time` · example `2025-01-01T00:00:00.000Z`

      ISO 8601 timestamp.

    - **`code`** · `string` · required

      Machine-readable error code.

    - **`message`** · `string` · required

      Optional error details for debugging.
