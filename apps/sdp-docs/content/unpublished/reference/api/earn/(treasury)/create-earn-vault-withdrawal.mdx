<ApiEndpoint method="POST" path="/v1/earn/vault-withdrawals" />

Call vault-withdrawal-options first to select a supported route, then quote the direct exit when minAmountOut is required. A strategy disabled for new deposits remains exitable. Provider-order exits finish only when the provider completes the payout. A new intentional operation needs a new Idempotency-Key, even with identical terms. Retrying an uncertain operation must reuse its key and exact payload.

Requires an [API key](/docs/developing-with-sdp/authentication) with the `earn.execute` action.

## Headers

- **`x-project-id`** · `string` · min length 1 · example `prj_example`

  Required for dashboard sessions. API keys use their assigned project.

- **`Idempotency-Key`** · `string` · required · pattern `^[\x20-\x7e]{1,255}$` · example `idempotency_example_12345`

  Idempotency key for safely retrying mutating requests. 1-255 printable ASCII characters; echoed back on the response.

## Request body

`application/json` · required

- **`positionId`** · `string` · required · min length 1 · max length 128

- **`shares`** · `string` · required · max length 128 · pattern `^\d+(\.\d+)?$`

- **`minAmountOut`** · `string` · max length 128 · pattern `^\d+(\.\d+)?$`

## Example request

```bash tab="cURL"
curl -X POST 'https://api.solana.com/v1/earn/vault-withdrawals' \
  -H "Authorization: Bearer $SDP_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d '{
    "positionId": "position_example",
    "shares": "example"
  }'
```
