<ApiEndpoint method="POST" path="/v1/earn/vault-withdrawal-requests/{withdrawalRequestId}/cancel" />

Solver requests return escrowed shares only after the deadline; operator cancellation leaves the wallet holding intermediate tokens instead of restoring the original shares. Fulfillment may race cancellation, so track the returned request. A new intentional operation needs a new Idempotency-Key, even with identical terms. Retrying an uncertain operation must reuse its key and exact payload.

Requires an [API key](/docs/developing-with-sdp/authentication) with the `earn.manage` action.

## Path parameters

- **`withdrawalRequestId`** · `string` · required · min length 1 · max length 128

## Headers

- **`x-project-id`** · `string` · min length 1 · example `prj_example`

  Required for dashboard sessions. API keys use their assigned project.

- **`Idempotency-Key`** · `string` · required · pattern `^[\x20-\x7e]{1,255}$` · example `idempotency_example_12345`

  Idempotency key for safely retrying mutating requests. 1-255 printable ASCII characters; echoed back on the response.

`application/json` · required
