<Callout type="info">
This operation is internal. It is not part of the partner-facing Earn API.
</Callout>


<ApiOperation>

<ApiEndpoint method="POST" path="/v1/earn/vault-queued-withdrawal-previews" />

Read the live withdrawal options first and resolve blockingIssues before confirming. Nothing moves.

Requires an [API key](/docs/developing-with-sdp/authentication) with the `earn.read` action.

## Headers

- **`x-project-id`** · `string` · min length 1 · example `prj_example`

  Required for dashboard sessions. API keys use their assigned project.

## Request body

`application/json` · required

Any of:

- **object**

  - **`positionId`** · `string` · required · min length 1 · max length 128

  - **`shares`** · `string` · required · max length 128 · pattern `^\d+(\.\d+)?$`

  - **`mechanism`** · `string` · always `solverQueue`

  - **`discountBps`** · `integer` · required · min 0 · max 10000

  - **`deadlineSeconds`** · `integer` · required · greater than 0 · max 7776000

- **object**

  - **`positionId`** · `string` · required · min length 1 · max length 128

  - **`shares`** · `string` · required · max length 128 · pattern `^\d+(\.\d+)?$`

  - **`mechanism`** · `string` · required · always `operatorRedemption`

- **object**

  - **`positionId`** · `string` · required · min length 1 · max length 128

  - **`intermediateAmount`** · `string` · required · max length 128 · pattern `^\d+(\.\d+)?$`

  - **`mechanism`** · `string` · required · always `operatorRedemption`

## Responses

- **`200`** Result

  - **`data`** · `object` · required

    Any of:

    - **object**

      - **`positionId`** · `string` · required

      - **`assetMint`** · `string` · required · min length 32 · max length 44 · pattern `^[1-9A-HJ-NP-Za-km-z]{32,44}$` · example `2b1kV6DkPAnxd5ixfnxCpjxmKwqjjaYmCZfHsFu24GXo`

        Base58 Solana mint address.

      - **`shares`** · `string` · required · max length 128 · pattern `^(?=.*[1-9])\d+(\.\d+)?$` · example `25`

        Positive decimal string with at least one non-zero digit; never a float.

      - **`shareDecimals`** · `integer` · required · min 0 · max 38

      - **`assets`** · `string` · required · max length 128 · pattern `^(?=.*[1-9])\d+(\.\d+)?$` · example `9.975`

        Expected payout after the selected discount, in asset units.

      - **`assetDecimals`** · `integer` · required · min 0 · max 38

      - **`discountBps`** · `integer` · required · min 0 · max 10000

      - **`maturityTimestamp`** · `string` · required · pattern `^\d+$` · example `1789722000`

        Expected Unix time when solver fulfilment may begin.

      - **`deadlineTimestamp`** · `string` · required · pattern `^\d+$` · example `1789808400`

        Expected Unix deadline. Fulfilment is allowed through this instant; cancellation is allowed only after it.

      - **`blockingIssues`** · `object[]` · required

        - **`code`** · `string` · required · example `SHARE_LOCKED`

        - **`message`** · `string` · required

    - **object**

      - **`positionId`** · `string` · required

      - **`mechanism`** · `string` · required · always `operatorRedemption`

      - **`shares`** · `string` · required · max length 128 · pattern `^\d+(\.\d+)?$` · example `10`

        Position shares the request burns, in share units; "0" when it redeems intermediate the owner already holds.

      - **`shareDecimals`** · `integer` · required · min 0 · max 38

      - **`intermediateMint`** · `string` · required · min length 32 · max length 44 · pattern `^[1-9A-HJ-NP-Za-km-z]{32,44}$` · example `2b1kV6DkPAnxd5ixfnxCpjxmKwqjjaYmCZfHsFu24GXo`

        Token the request creates or delegates for later operator settlement.

      - **`intermediateAmount`** · `string` · required · max length 128 · pattern `^(?=.*[1-9])\d+(\.\d+)?$` · example `25`

        Expected intermediate-token amount, in that token's units.

      - **`assetMint`** · `string` · required · min length 32 · max length 44 · pattern `^[1-9A-HJ-NP-Za-km-z]{32,44}$` · example `2b1kV6DkPAnxd5ixfnxCpjxmKwqjjaYmCZfHsFu24GXo`

        Base58 Solana mint address.

      - **`assets`** · `string` · required · max length 128 · pattern `^(?=.*[1-9])\d+(\.\d+)?$` · example `10`

        Expected par payout when the operator completes the redemption.

      - **`assetDecimals`** · `integer` · required · min 0 · max 38

      - **`blockingIssues`** · `object[]` · required

        - **`code`** · `string` · required · example `SHARE_LOCKED`

        - **`message`** · `string` · required

  - **`meta`** · `object` · required

    Response metadata.

    - **`requestId`** · `string` · required · min length 1 · example `req_example`

      Request identifier for tracing.

    - **`timestamp`** · `string` · required · format `date-time` · example `2025-01-01T00:00:00.000Z`
