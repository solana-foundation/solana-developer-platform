<ApiEndpoint method="POST" path="/v1/earn/vault-deposits" />

Quote first when the strategy requires minSharesOut. Swap-funded deposits stay atomic; if the combined transaction cannot fit, the request is refused without sending. Convert funds separately or deposit the vault's own token before retrying. A new intentional operation needs a new Idempotency-Key, even with identical terms. Retrying an uncertain operation must reuse its key and exact payload.

Requires an [API key](/docs/developing-with-sdp/authentication) with the `earn.execute` action.

## Headers

- **`x-project-id`** · `string` · min length 1 · example `prj_example`

  Required for dashboard sessions. API keys use their assigned project.

- **`Idempotency-Key`** · `string` · required · pattern `^[\x20-\x7e]{1,255}$` · example `idempotency_example_12345`

  Idempotency key for safely retrying mutating requests. 1-255 printable ASCII characters; echoed back on the response.

## Request body

`application/json` · required

- **`strategyId`** · `string` · required · min length 1

- **`custodyWalletId`** · `string` · required · min length 1

- **`amount`** · `string` · required · max length 128 · pattern `^\d+(\.\d+)?$`

- **`minSharesOut`** · `string` · max length 128 · pattern `^\d+(\.\d+)?$`

- **`sourceTokenMint`** · `string`

- **`swapSlippageBps`** · `integer` · min 1 · max 500
