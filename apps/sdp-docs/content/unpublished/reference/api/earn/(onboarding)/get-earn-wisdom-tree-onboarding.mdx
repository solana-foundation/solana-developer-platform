<ApiOperation>

<ApiEndpoint method="GET" path="/v1/earn/onboarding/wisdomtree/{counterpartyId}" />

Requires earn.read for reads and earn.execute plus Idempotency-Key for writes. Use current form rules and the applicant's own agreement answers. No applicant data is persisted by SDP. A submitted application is not approval. A timeout requires reconciliation before another create. Child organization and person GUIDs are derived from the durable mapping; callers cannot select them.

Requires an [API key](/docs/developing-with-sdp/authentication) with the `earn.read` action.

## Path parameters

- **`counterpartyId`** · `string` · required · min length 1

## Headers

- **`x-project-id`** · `string` · min length 1 · example `prj_example`

  Required for dashboard sessions. API keys use their assigned project.

## Responses

- **`200`** Onboarding result

  - **`data`** · `object` · required

    - **`counterpartyId`** · `string` · required

    - **`state`** · `string` · required · one of `claimed`, `linked`, `archived`

    - **`reconciliationRequired`** · `boolean`

    - **`providerStatus`** · `string`

    - **`organizationGuid`** · `string | null` · format `uuid`

    - **`personGuid`** · `string | null` · format `uuid`

    - **`corrections`** · `object[]`

      - **`*`** · `any`

    - **`correctionDueAt`** · `string | null`

  - **`meta`** · `object` · required

    Response metadata.

    - **`requestId`** · `string` · required · min length 1 · example `req_example`

      Request identifier for tracing.

    - **`timestamp`** · `string` · required · format `date-time` · example `2025-01-01T00:00:00.000Z`

      ISO 8601 timestamp.

- **`400`** Bad Request

  - **`error`** · `object` · required

    Standard error payload.

    - **`code`** · `string` · required

      Machine-readable error code.

    - **`message`** · `string` · required

      Human-readable error message.

    - **`details`** · `object`

      Optional error details for debugging.

      - **`*`** · `any`

  - **`meta`** · `object`

    - **`requestId`** · `string` · min length 1 · example `req_example`

      Request identifier for tracing.

- **`401`** Unauthorized

  Same fields as `400`.

- **`403`** Forbidden. Requires the `earn.read` action: an API key must hold it (a module's `manage` or `execute` also covers its `read`), and a signed-in member's organization role must include it. Without it the error is INSUFFICIENT_PERMISSIONS and `error.details.action` names the action. Any other 403 names its own reason.

  Same fields as `400`.

- **`404`** Not Found

  Same fields as `400`.

- **`409`** Conflict

  Same fields as `400`.

- **`413`** Payload Too Large

  Same fields as `400`.

- **`429`** Too Many Requests

  Same fields as `400`.

- **`500`** Internal Server Error

  Same fields as `400`.

- **`503`** Service Unavailable

  Same fields as `400`.
