Create a custody wallet, check its balances, and use API key grants to control what an integration can do with it.

## Start here

- [Create a wallet](/docs/guides/setup-wallets): choose a provider and provision your first wallet.
- [Wallet balances](/docs/wallet-operations/balances): read token balances and optional USD valuations.
- [Manage API keys](/docs/developing-with-sdp/manage-api-keys): grant only the actions and wallets an integration needs.

See the [Wallets API reference](/docs/reference/api/wallets) for request and response details.
