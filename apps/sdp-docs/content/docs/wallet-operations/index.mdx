This section covers balance visibility for a custody wallet. What a caller may do with a wallet is set on the API key: its role and permissions, the wallets it is bound to, and its [allowed operations](/docs/developing-with-sdp/manage-api-keys#allowed-operations).

## What's in this section

- [Wallet balances](/docs/wallet-operations/balances) — retrieve token balances and optional USD valuations for a custody wallet.

## API surface

The balance endpoint remains under `/v1/payments/wallets` because it was introduced with the Payments API. Its behavior is wallet-wide.
