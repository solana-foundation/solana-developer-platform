---
title: Set up your organization and projects
description: Create your SDP organization, and learn how a project scopes the work inside it.
---

Every SDP user works inside an **organization**. An organization is a team workspace that holds one
or more **projects**. Each project is a provisioned environment with its own API keys, wallets, and
members.

This guide creates your organization. It then explains how a project scopes your resources.

## 1. Sign up

Go to [platform.solana.com](https://platform.solana.com) and select **Dashboard**. On the sign-in
screen, select **Sign up** to create an account.

![SDP sign-in screen with a Sign up link](/images/getting-started/sign-in.png)

Enter your email address and a password to create the account.

![Create your account screen](/images/getting-started/create-account.png)

## 2. Create or select an organization

After you sign in, SDP asks you to set up your organization.

1. Upload a logo.
2. Enter your organization name.
3. Select **Continue**.

![Setup your organization screen, with the logo and name fields filled in](/images/getting-started/setup-organization.png)

If you already belong to an organization, the sidebar shows its name. Select the name to open the
list of your organizations. From that list you can change organization, or create another one.

<img src="/docs/images/getting-started/org-switcher.png" alt="The open organization list, showing the current organization and its projects" width="436" style={{ display: "block", maxWidth: "100%" }} />

## 3. Organize with projects

A **project** is a provisioned environment inside your organization. It is a sandbox project or a
production project. Each project has its own API keys, wallets, tokens, and members, so two teams
do not share the same wallets and tokens.

See the [Projects API reference](/docs/reference/api/projects) to manage projects from your own
code.
