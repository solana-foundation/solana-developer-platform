---
title: Set up wallets
description: Initialize a custody provider, then create the custody wallets that sign your transactions.
---

A **custody wallet** is a Solana keypair that a custody provider holds and signs with. SDP sends
each signing request to the provider that holds the wallet's key.

Initialize a provider first. Then create the wallets that deploy tokens, mint tokens, send
transfers, and run other onchain operations.

## Supported providers

Four providers are available to every organization. The others need access to be granted for your
organization before the provider appears. Ask your SDP contact to grant that access.

| Provider | Description | Availability |
| --- | --- | --- |
| **Privy** | An embedded wallet infrastructure platform. | Available to every organization |
| **Fireblocks** | A digital asset infrastructure company. | Access granted per organization |
| **Coinbase CDP** | Embedded wallets for developers. | Available to every organization |
| **Para** | A wallet and authentication suite. | Available to every organization |
| **Turnkey** | A non-custodial wallet infrastructure platform. | Available to every organization |
| **DFNS** | Digital asset wallet infrastructure. | Access granted per organization |
| **Anchorage** | Regulated institutional crypto custody. | Access granted per organization |

### 1. Open the Wallets page

Select **Wallets** in the sidebar. If you have not set up your organization yet, complete the
[organization setup](/docs/guides/setup-organization) first.

### 2. Choose a custody provider

The Wallets page shows the providers your organization can use. Each one has a **New wallet**
button. Choose the provider that fits your setup.

![Wallets page showing one card per custody provider, each with a New wallet button](/images/getting-started/wallet-providers.png)

### 3. Create the wallet

1. Select **New wallet** on the provider you chose.
2. Enter a label for the wallet.
3. Select **Create wallet**.

<img src="/docs/images/getting-started/wallet-create-modal.png" alt="The new wallet dialog, with the label field filled in" width="696" style={{ display: "block", maxWidth: "100%" }} />

### 4. View your wallet

SDP creates the wallet, then shows its card on the Wallets page with the wallet's address, wallet
ID, and balance.

![Wallets page showing the card of the new wallet](/images/getting-started/wallet-created.png)

To create another wallet, select **Create wallet** and repeat step 3.

### 5. Provider capabilities

Each provider supports a different set of operations. The wallet card shows them as chips:

- **Issuance**. The wallet can deploy and mint tokens.
- **Transfers**. The wallet can sign payment transactions.
- **Compliance**. The wallet can sign freeze and unfreeze instructions.

#### 1. Initialize the signing provider

<Tabs items={["curl", "TypeScript", "Java"]}>
<Tab value="curl">
```bash title="Terminal"
curl -X POST https://api.solana.com/v1/wallets/initialize \
  -H "Authorization: Bearer sk_test_..." \
  -H "Content-Type: application/json" \
  -d '{
    "provider": "privy",
    "walletLabel": "Master wallet"
  }'
```
</Tab>
<Tab value="TypeScript">
```typescript title="initialize-wallet-provider.ts"
const response = await fetch("https://api.solana.com/v1/wallets/initialize", {
  method: "POST",
  headers: {
    "Authorization": "Bearer sk_test_...",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    provider: "privy",
    walletLabel: "Master wallet",
  }),
});
const { data } = await response.json();
// data: { configId, publicKey, walletId }
```
</Tab>
<Tab value="Java">
```java title="InitializeWalletProvider.java"
HttpRequest request = HttpRequest.newBuilder()
    .uri(URI.create("https://api.solana.com/v1/wallets/initialize"))
    .header("Authorization", "Bearer sk_test_...")
    .header("Content-Type", "application/json")
    .POST(HttpRequest.BodyPublishers.ofString("""
        {
          "provider": "privy",
          "walletLabel": "Master wallet"
        }"""))
    .build();
```
</Tab>
</Tabs>

#### 2. Create additional wallets

<Tabs items={["curl", "TypeScript", "Java"]}>
<Tab value="curl">
```bash title="Terminal"
curl -X POST https://api.solana.com/v1/wallets \
  -H "Authorization: Bearer sk_test_..." \
  -H "Content-Type: application/json" \
  -d '{
    "label": "Mint authority wallet",
    "purpose": "mint_authority",
    "setDefault": false
```

The `purpose` field is optional metadata in the API. The create-wallet flow in the dashboard does
not offer a wallet purpose.

#### 3. List wallets

<Tabs items={["curl", "TypeScript", "Java"]}>
<Tab value="curl">
```bash title="Terminal"
curl "https://api.solana.com/v1/wallets?view=summary" \
  -H "Authorization: Bearer sk_test_..."
```
</Tab>
<Tab value="TypeScript">
```typescript title="list-wallets.ts"
const response = await fetch("https://api.solana.com/v1/wallets?view=summary", {
  headers: { "Authorization": "Bearer sk_test_..." },
});
const { data } = await response.json();
// data.wallets includes walletId, publicKey, provider, label, purpose, and status
```
</Tab>
<Tab value="Java">
```java title="ListWallets.java"
HttpRequest request = HttpRequest.newBuilder()
    .uri(URI.create("https://api.solana.com/v1/wallets?view=summary"))
    .header("Authorization", "Bearer sk_test_...")
    .GET()
    .build();
```
</Tab>
</Tabs>

`GET /v1/wallets` returns two identifiers for each wallet. `walletId` is the provider wallet ID,
for example `privy_wallet_123`. `id` is the SDP wallet ID, for example `cwlt_abc123`.

Use the provider wallet ID (`walletId`) to set the default wallet, and to bind an API key to a
wallet. Use the SDP wallet ID (`id`) as `sourceCustodyWalletId` or `destinationCustodyWalletId` on
the payments and ramps endpoints. See
[Which wallet identifier to use](/docs/wallet-operations#which-wallet-identifier-to-use) for the
full table.

#### 4. Set a default wallet

`POST /v1/wallets/default-wallet` takes the provider wallet ID in its `walletId` field. It does not
accept the SDP wallet ID, and it does not accept the wallet address.

<Tabs items={["curl", "TypeScript", "Java"]}>
<Tab value="curl">
```bash title="Terminal"
curl -X POST https://api.solana.com/v1/wallets/default-wallet \
  -H "Authorization: Bearer sk_test_..." \
  -H "Content-Type: application/json" \
  -d '{ "walletId": "privy_wallet_123" }'
```
</Tab>
<Tab value="TypeScript">
```typescript title="set-default-wallet.ts"
await fetch("https://api.solana.com/v1/wallets/default-wallet", {
  method: "POST",

    "Content-Type": "application/json",
  },
  body: JSON.stringify({ walletId: "privy_wallet_123" }),

```
</Tab>

```java title="SetDefaultWallet.java"

```
