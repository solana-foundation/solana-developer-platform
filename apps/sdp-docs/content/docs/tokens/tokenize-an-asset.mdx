Use this page to issue a stablecoin, a tokenized security, a loyalty token, or another asset
through the Solana Developer Platform. It takes you from the business decision to the first API
call.

## Choose a token model

Select the **Template** that matches the compliance and operational requirements of your asset.

| Asset model | Template | Typical controls |
| --- | --- | --- |
| Fiat-backed stablecoin | `stablecoin` | Mint authority, freeze authority, pausable, permanent delegate |
| Tokenized security or RWA | `tokenized-security` | Allowlist on by default, freeze authority, pausable, permanent delegate |
| Loyalty, rewards, or utility token | `custom` | Manually selected extensions |
| Non-standard asset | `custom` | Manually selected extensions |

These templates cover the common cases. `GET /v1/issuance/templates` returns every template that is
available to your project.

Custody wallets hold the authorities of your token by default. SDP can therefore deploy the token,
mint supply, and run compliance actions without an external signer.

Each step links to its own guide. Each guide gives instructions for the dashboard and for the API.

1. [Set up your organization and projects](/docs/guides/setup-organization)

5. [Deploy a token](/docs/tokens/deploy-a-token). SDP creates the mint account onchain.

   transfers, or seize tokens.
10. [Manage token settings](/docs/tokens/manage-token-settings). Rotate or clear a token authority.

## Core API endpoints

| Method | Endpoint | Purpose |
| --- | --- | --- |
| `GET` | `/v1/issuance/templates` | List available token templates |
| `POST` | `/v1/issuance/tokens` | Create a token draft |
| `POST` | `/v1/issuance/tokens/{tokenId}/deploy` | Deploy the draft to Solana |
| `POST` | `/v1/issuance/tokens/{tokenId}/mint` | Mint new supply |
| `POST` | `/v1/issuance/tokens/{tokenId}/burn` | Reduce supply |
| `POST` | `/v1/issuance/tokens/{tokenId}/allowlist` | Add a Token Access Control entry |
| `POST` | `/v1/issuance/tokens/{tokenId}/freeze` | Freeze the balance of one holder |
| `POST` | `/v1/issuance/tokens/{tokenId}/pause` | Pause every transfer of the token |
| `POST` | `/v1/payments/transfers` | Transfer tokens |

See the full schema in the [Issuance API reference](/docs/reference/api/issuance) and the
[Payments API reference](/docs/reference/api/payments).

## Operational constraints

- SDP saves a new token as a **draft**. Deploy the draft before you mint or transfer the token.
- A paused token blocks minting and transfers. Unpause the token to run those operations again.
- Freeze and unfreeze accept the wallet address of a holder. SDP derives the associated token
  account from that address.
- Every SDP operation needs the matching authority on a custody wallet. If someone rotated an
  authority outside SDP, rotate it back to a controlled wallet. Do this before you deploy, mint, or
  run a compliance action.
