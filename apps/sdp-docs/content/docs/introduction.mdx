Solana Developer Platform (SDP) gives your app one API for the Solana services it uses. Set up a project in the dashboard, then call the API with a key scoped to that project.

## Why SDP

Institutional assets are moving onchain. In October 2026, RWA.xyz tracked [about $39.5 billion in tokenized real-world assets](https://app.rwa.xyz/), including [about $5.2 billion on Solana](https://app.rwa.xyz/networks/solana). [Tokenized stocks](https://app.rwa.xyz/stocks) are one part of that growth.

Assets at this scale need custody, enforceable compliance, and auditable controls. SDP puts the services your deployment supports behind one project-scoped API, so you can build on Solana without wiring up every provider yourself.

## How it fits together

- **Projects** separate environments, keys, wallets, and team access. Start in your sandbox project, then move to production.
- **Providers** supply the services behind SDP. You choose the providers each project uses; your app calls the same SDP API either way.
- **Access** is explicit. An API key holds only the actions you grant it, and sensitive operations leave an audit trail.
