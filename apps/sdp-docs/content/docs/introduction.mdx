Solana Developer Platform (SDP) gives your app one API for the Solana services it uses. Set up a project in the dashboard, then make requests with a key scoped to that project.

## How it fits together

- **Projects** separate environments, keys, wallets, and team access. Start in a sandbox before moving to production.
- **Providers** supply the services behind SDP. Configure the providers you use for each project; your app calls the same SDP API.
- **Access** is explicit. API keys hold only the actions you grant, and sensitive operations leave an audit trail.
