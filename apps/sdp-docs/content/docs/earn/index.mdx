Earn lets your customers earn yield on stablecoins from wallets they already
hold. A deposit is three requests and one signature, and the position stays in
your customer's wallet.

| Step | Request |
| --- | --- |
| 1. Pick a strategy | [`GET /v1/earn/strategies`](/docs/reference/api/earn/list-earn-strategies) |
| 2. Build the deposit | [`POST /v1/earn/external-wallet/deposit-transactions`](/docs/reference/api/earn/create-earn-external-wallet-deposit-transaction) |
| 3. Submit it, signed by the wallet | [`POST /v1/earn/external-wallet/deposits`](/docs/reference/api/earn/create-earn-external-wallet-deposit) |

## How it works

<EarnFlow>

- **Customer's wallet**

  Signs a deposit of the strategy's deposit token.

- **Strategy**

  Issues shares or a yield-bearing token to the customer's wallet.

- **Customer's wallet**

  Receives the payout when a withdrawal settles.

</EarnFlow>

Your backend builds each transaction, your customer's wallet signs it, and SDP
broadcasts and tracks it. Returns, losses, fees, and withdrawal timing depend
on the strategy. An APY is a rate, not a promise.

## Common questions

| Question | Answer |
| --- | --- |
| Do I need the rest of SDP? | No. Create an account, create an API key, and call Earn. |
| Who holds the funds? | The strategy holds deposits, and your customer's wallet holds the position. SDP never holds a key or a balance. [Trace it onchain](/docs/earn/concepts#where-funds-go). |
| Can one integration serve many customers? | Yes. [One API key serves every customer wallet](/docs/earn/concepts#one-integration-many-customers), and each balance is recorded per wallet. |
| What does it cost? | Network fees and the strategy's own fees. [No transaction SDP builds pays SDP](/docs/earn/concepts#what-it-costs). |
| Who checks eligibility? | You do, for your customers, under [each strategy's terms](/docs/earn/strategies#confirm-eligibility). |
