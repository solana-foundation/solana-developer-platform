Earn puts stablecoins to work in DeFi and real-world-asset strategies through
one API. The position stays in the wallet that deposited.

## Two ways to use Earn

| | Embedded Yield | Treasury |
| --- | --- | --- |
| Use it to | Offer yield to your customers inside your app | Earn on your organization's own funds |
| Wallet | Your customer's own. SDP holds no key for it. | A custody wallet in your SDP project |
| Who signs | Your customer's wallet | SDP, through the wallet's custody provider |
| A deposit takes | Three requests and one signature | Two requests and no signature |
| Start with | [Embedded Yield quickstart](/docs/earn/quickstart) | [Treasury quickstart](/docs/earn/treasury-quickstart) |

Both use the same [strategies](/docs/earn/strategies) and sandbox, and one
project can use both.

## How it works

<EarnFlow>

- **Wallet**

  Deposits the strategy's deposit token.

- **Strategy**

  Issues shares or a yield-bearing token to the same wallet.

- **Wallet**

  Receives the payout when a withdrawal settles.

</EarnFlow>

SDP builds each transaction and tracks it to settlement. Returns, losses,
fees, and withdrawal timing depend on the strategy. An APY is a rate, not a
promise.

## Common questions

| Question | Answer |
| --- | --- |
| Do I need the rest of SDP? | For Embedded Yield, no: create an account, create an API key, and call Earn. Treasury also needs a [custody wallet](/docs/guides/setup-wallets) in your project. |
| Who holds the funds? | The strategy holds deposits, and the wallet that deposited holds the position. SDP holds no key for a customer's wallet. [Trace it onchain](/docs/earn/concepts#where-funds-go). |
| Can one integration serve many customers? | Yes. [One API key serves every customer wallet](/docs/earn/concepts#one-integration-many-customers), and each balance is recorded per wallet. |
| What does it cost? | Network fees and the strategy's own fees. [No transaction SDP builds pays SDP](/docs/earn/concepts#what-it-costs). |
| Who checks eligibility? | You do, for your customers and your organization, under [each strategy's terms](/docs/earn/strategies#confirm-eligibility). |
