Earn puts vault, lending and real-world-asset yield strategies behind one API.
Your customer's wallet signs every deposit and withdrawal, and SDP broadcasts it
and tracks it to settlement. Funds move between the customer's wallet and the
provider's program; SDP never holds them
([follow the funds](/docs/earn/concepts#follow-the-funds)).

<EarnFlow>

- **Prepare**

  `POST /v1/earn/deposit` returns an operation with an unsigned transaction.

- **Sign and submit**

  Your customer's wallet signs it, and `/submit` hands SDP the exact bytes.

- **Track**

  Poll `GET /v1/operations/{operationId}` until it completes.

</EarnFlow>

Any Solana wallet can sign, and none needs registering in SDP. Start with the
[quickstart](/docs/earn/quickstart), or
[run the example](https://github.com/solana-foundation/solana-developer-platform/tree/main/examples/earn-quickstart)
locally with no key, wallet or funds.

## Endpoints

| Endpoint | What it does |
| --- | --- |
| `GET /v1/earn/discovery` | Lists strategies, their rates and what each supports. |
| `GET /v1/earn/positions` | Reads a wallet's holdings and totals. |
| `POST /v1/earn/deposit` | Prepares a deposit into a strategy. |
| `POST /v1/earn/withdraw` | Prepares a withdrawal from a position. |
| `GET /v1/operations`, `GET /v1/operations/{operationId}` | Track deposits and withdrawals. |
| `POST /v1/operations/{operationId}/submit` | Sends the signed transaction. |
| `POST /v1/operations/{operationId}/refresh` | Chooses a withdrawal route before you sign. |
| `POST /v1/operations/{operationId}/cancel` | Abandons an operation before you sign. |
