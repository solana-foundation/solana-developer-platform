Earn puts vault, lending and real-world-asset yield strategies behind one API.
Your customer's wallet signs every deposit and withdrawal, and SDP broadcasts it
and tracks it to settlement. Funds move between the customer's wallet and the
provider; SDP never holds them
([follow the funds](/docs/earn/concepts#follow-the-funds)).

<EarnFlow>

- **Prepare**

  `POST /v1/earn/deposit` returns an operation with an unsigned transaction.

- **Sign and submit**

  Your customer's wallet signs it, and `/submit` hands SDP the exact bytes.

- **Track**

  Poll `GET /v1/operations/{operationId}` until it completes.

</EarnFlow>

Any Solana wallet can sign, and you don't register it with SDP; a few
real-world-asset funds accept only
[issuer-approved wallets](/docs/earn/integration-details#provider-eligibility).
Start with the
[quickstart](/docs/earn/quickstart), or
[run the example](https://github.com/solana-foundation/solana-developer-platform/tree/main/examples/earn-quickstart)
locally with no key, wallet or funds.

## Endpoints

What each endpoint takes and returns is in the [API overview](/docs/earn/api-overview).

| Endpoint | What it does |
| --- | --- |
| [`GET /v1/earn/discovery`](/docs/reference/api/earn/discover-earn-strategies) | Lists strategies, their rates and what each supports. |
| [`GET /v1/earn/positions`](/docs/reference/api/earn/list-earn-core-positions) | Reads a wallet's holdings and totals. |
| [`GET /v1/earn/positions/{positionId}`](/docs/reference/api/earn/get-earn-position) | Reads one position's latest balance and withdrawal state. |
| [`POST /v1/earn/deposit`](/docs/reference/api/earn/prepare-earn-deposit) | Prepares a deposit into a strategy. |
| [`POST /v1/earn/withdraw`](/docs/reference/api/earn/prepare-earn-withdrawal) | Prepares a withdrawal from a position. |
| [`GET /v1/operations`](/docs/reference/api/earn/list-operations) | Lists a wallet's deposits and withdrawals. |
| [`GET /v1/operations/{operationId}`](/docs/reference/api/earn/get-operation) | Reads one operation's status and next action. |
| [`POST /v1/operations/{operationId}/submit`](/docs/reference/api/earn/submit-operation) | Sends the signed transaction. |
| [`POST /v1/operations/{operationId}/refresh`](/docs/reference/api/earn/refresh-operation) | Chooses a withdrawal route before you sign. |
| [`POST /v1/operations/{operationId}/cancel`](/docs/reference/api/earn/cancel-operation) | Abandons a withdrawal before you choose its route. |
