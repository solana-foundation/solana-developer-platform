Earn aggregates strategies from integrated providers. A strategy may be a vault,
lending market or RWA product. Treasury and Embedded Yield use the same
catalogue, positions and asynchronous operations.

[Run the TypeScript example](https://github.com/solana-foundation/solana-developer-platform/tree/codex/earn-core-api/examples/earn-quickstart)
or follow the [quickstart](/docs/earn/quickstart). The local dry-run needs no
account or funds. These pages describe this PR's core contract; deployment
availability follows the normal release channel and serving version.

Use your SDP API key with any compatible Solana wallet: prepare with
`ownerAddress`, sign the returned transaction through your wallet integration,
then submit the signed bytes. You do not need a wallet registered in SDP.
An existing connected wallet's `walletId` is an optional alternative.

## Core actions

- `GET /v1/earn/discovery` lists strategies, rates and supported actions.
- `GET /v1/earn/positions` reads holdings and optional portfolio totals.
- `POST /v1/earn/deposit` prepares a deposit using a strategy ID.
- `POST /v1/earn/withdraw` prepares a withdrawal using a position ID.

Every deposit or withdrawal returns an operation. Review its terms, submit its
current action and track its next action until delivery is verified. A worker
coordinates configured-wallet signing and broadcast.

Start with the [quickstart](/docs/earn/quickstart), then read about
[strategies](/docs/earn/strategies), [deposits](/docs/earn/deposits),
[positions](/docs/earn/balances) and [withdrawals](/docs/earn/withdrawals).
