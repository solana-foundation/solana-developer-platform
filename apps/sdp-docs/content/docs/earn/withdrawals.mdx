---
module: earn
title: Withdraw funds
description: Prepare a withdrawal from a position, choose its exit route when offered, and track the payout.
---

Send `POST /v1/earn/withdraw` with a position from
[`GET /v1/earn/positions`](/docs/earn/balances):

```json title="withdrawal.json"
{
  "positionId": "<position-id>",
  "amount": { "kind": "all" }
}
```

The position fixes the strategy and the owner, and the payout goes back to that
owner. `slippageBps` is optional and sits at the top level. See
[all withdrawal parameters](/docs/reference/api/earn/prepare-earn-withdrawal).

| `amount.kind` | Withdraws |
| --- | --- |
| `all` | The whole position. |
| `shares` | `value` shares. |
| `token` | Shares worth `value` of the strategy's deposit token `mint`. |
| `intermediate` | `value` of a held intermediate token `mint`, for strategies that redeem through one. |

## Choose an exit route

Some strategies offer more than one exit, such as an instant swap and a delayed
redemption. Then `nextAction.type` is `select_option`, and `terms.options` lists
each route with its `settlement`, `estimatedSeconds` and `amount`. Call
`POST /v1/operations/{operationId}/refresh` with the chosen `optionId` and the
current `actionId` and `version`. SDP prepares that route's transaction for you
to review, and the route stays fixed on later refreshes.

While the withdrawal waits for your choice, `canCancel` is `true` and
`POST /v1/operations/{operationId}/cancel` abandons it. Cancel needs the
`earn.manage` grant.

## Sign, submit and track

Sign and submit as for a [deposit](/docs/earn/deposits#sign-and-submit), then
poll the operation. A delayed redemption stays in progress until the provider
pays out: a request ID or escrowed shares are not a payout, and there is no
separate claim step. `completed` means SDP verified the payout; a `null`
`result.settledAmount` is unknown, not zero.

Once submitted, a withdrawal can't be refreshed or cancelled, even while
queued. Only a `failed` withdrawal lets you prepare a new one, with a new
`Idempotency-Key`. If shares end up stuck in an expired queue request,
[recover them](/docs/earn/integration-details#recover-expired-withdrawal-escrow).
