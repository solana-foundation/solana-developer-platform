---
module: earn
title: Withdraw funds
description: Prepare position exits and track delivery, claims and cancellation.
---

Prepare an exit with `POST /v1/earn/withdraw` using a position ID:

```json
{
  "positionId": "earn_position_example",
  "amount": { "kind": "all" }
}
```

The position determines its strategy and owner. Other quantity kinds are
`shares`, `token` and held `intermediate`; each quantity carries its own units.
Payout returns to that owner.

## Choose and review an exit

Preparation advertises available instant or delayed exits in `terms.options`.
When a choice is required, execute its `optionId` with the current action ID and
version, then review the prepared transaction. A client cannot invent a route
or approve changed terms with an old action identity.

Sign when requested and execute through the shared operation endpoint. All
signing, provider approvals and broadcast run asynchronously in the worker.

## Track delivery or cancellation

Poll the operation through request, claim and settlement. A provider request ID
or escrowed shares is not payout evidence. Later steps can require another
explicit review and execution.

Request cancellation through `POST /v1/operations/{operationId}/cancel` with
`earn.manage`. Cancellation records intent; a chain or provider race can keep
it pending. Executing an onchain cancellation also requires `earn.execute`.
The result distinguishes delivered assets, returned shares and held
intermediate tokens. Null settled amounts remain unknown.
