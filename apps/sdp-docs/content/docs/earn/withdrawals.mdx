---
module: earn
title: Withdraw funds
description: Prepare position exits and track delivery and cancellation.
---

Prepare an exit with `POST /v1/earn/withdraw` using a position ID:

```json
{
  "positionId": "earn_position_example",
  "amount": { "kind": "all" }
}
```

The position determines its strategy and owner. Other quantity kinds are
`shares`, `token` and held `intermediate`; each quantity carries its own units.
Payout returns to that owner.

## Choose and review an exit

For `nextAction.type="select_option"`, choose an advertised exit from
`terms.options`. Call `POST /v1/operations/{operationId}/refresh` with its
`optionId`, the current `actionId` and `version`, then review the newly prepared
transaction. Selection does not authorize execution. Later refreshes retain the
selected route instead of switching between instant and delayed exits.

Sign when requested and call `POST /v1/operations/{operationId}/submit` with the
new action identity and any required signed bytes. The worker handles configured
signing, provider approvals and broadcast asynchronously.

## Track delivery or cancellation

Poll the same operation through request and settlement. A provider request ID
or escrowed shares is not payout evidence. There is no separate claim endpoint.

Request cancellation through `POST /v1/operations/{operationId}/cancel` with
`earn.manage`. Cancellation records intent; a chain or provider race can keep
it pending. Executing an onchain cancellation also requires `earn.execute`.
The result distinguishes delivered assets, returned shares and held
intermediate tokens. Null settled amounts remain unknown.
