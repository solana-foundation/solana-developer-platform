Every deposit names a strategy. List the catalog, keep the strategies your
project can fund, and check each one's terms before you offer it.

## List the catalog

[`GET /v1/earn/strategies`](/docs/reference/api/earn/list-earn-strategies)
returns your project's strategies, largest first.

```bash title="Terminal"
curl -sS "https://api.solana.com/v1/earn/strategies?pageSize=100" \
  -H "Authorization: Bearer $SDP_API_KEY"
```

```json title="Response (trimmed)"
{
  "data": {
    "strategies": [
      {
        "id": "earn_strategy_3b6a81ce-00b0-4c5a-9761-cb359932e97e",
        "provider": "kamino",
        "providerReference": "C7N2fqV2GvhFghDf5PJSwstyjedjLNCY1cm2Ak7TeU83",
        "name": "Kamino Vault USDC",
        "sourceKind": "defi",
        "depositMints": ["4zMMC9srt5Ri5X14GAgXhaHii3GnPAEERYPJgZJDncDU"],
        "shareMint": "CeirL1mAehaM6g2EccgMUQwohNfnuyicskVQ4r9ekXk6",
        "apyType": "variable",
        "liquidityTerm": "instant",
        "status": "active",
        "depositSlippage": null,
        "withdrawalSlippage": null,
        "hostCluster": "devnet",
        "fundable": true
      }
    ],
    "total": 6,
    "page": 1,
    "pageSize": 100
  }
}
```

Read pages (`page`, and `pageSize` up to 100, default 20) until you have
`total` strategies. Filter with `sourceKind` (`defi` or `rwa`), `apyType`, or
`liquidityTerm`.

## Check that it takes deposits

| Check | Pass when |
| --- | --- |
| `status` | `"active"`. Paused and deprecated strategies take no new deposits. |
| `fundable` | `true`: the strategy exists on your project's network. |
| Deposit token | The wallet holds `depositMints[0]`, the token a deposit takes. |
| Preview | A [deposit preview](/docs/earn/deposits#preview-the-deposit) returns an empty `blockingIssues`. |
| Activation | SDP has activated the strategy's provider for your organization. |

In sandbox, `?cluster=mainnet-beta` lists mainnet strategies for browsing
only: they stay `fundable: false`.

SDP activates a provider once for all of an organization's projects. Until
then, previews and builds return `403`. Ask your SDP contact to activate it.

```json title="Response"
{
  "error": {
    "code": "FORBIDDEN",
    "message": "Kamino requires manual activation for this organization.",
    "details": { "reason": "provider_not_entitled" }
  }
}
```

## Read the slippage policy

`depositSlippage` and `withdrawalSlippage` say whether a transaction needs a
[floor from a live quote](/docs/earn/integration-details#slippage-floors):

| Policy | Deposit | Withdrawal |
| --- | --- | --- |
| `null` | Omit `minSharesOut`. | Omit `minAmountOut`. |
| `{ "quoteRequired": true, "defaultToleranceBps": 10 }` | Preview, then send `minSharesOut`. | Preview, then send `minAmountOut`. |

## Show rates and terms

| Field | How to show it |
| --- | --- |
| `currentApy` | A decimal rate: `"0.062"` is 6.2%. When absent, show "Unavailable", never 0%. |
| `apyType` | A `variable` rate moves with the strategy's returns; a `fixed` rate does not. |
| `liquidityTerm` | A label, not a promise. Read live [withdrawal options](/docs/earn/withdrawals#1-choose-a-route) before you offer a route. |
| `redemptionDelayDays` | Expected timing, not a guaranteed deadline. |
| `riskMetadata` | Facts the provider reports: fee rates such as `managementFeeBps` and `performanceFeeBps`, `tvlUsd`, `eligibility`, and `issuerControls`. |

An APY is a rate, not a guaranteed return. A token in the customer's own
wallet does not guarantee principal, backing, or liquidity.

## Confirm eligibility

SDP access authorizes API calls, not investment.

| Check | Who runs it |
| --- | --- |
| Is the provider active for your organization? | SDP. |
| May this customer hold this product? | You. Screen each customer and wallet against the provider's requirements. |
| Does the provider restrict the token? | The provider. An issuer can keep controls over its token, such as freezing an account, and a provider with a registry of approved wallets refuses a build for any other wallet with `400`. |

A strategy's `riskMetadata.eligibility` and `riskMetadata.issuerControls`
carry the rules its provider publishes. For a restricted product, confirm
investor, jurisdiction, wallet, subscription, and redemption requirements with
the provider, for each customer and wallet. One usable strategy does not make
a provider permissionless.

## Paused and deprecated strategies

Pausing or deprecating a strategy stops new deposits only. Existing positions
stay visible and [withdrawable](/docs/earn/withdrawals), subject to the
provider's liquidity.
