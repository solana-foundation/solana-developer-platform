Use `GET /v1/earn/discovery` to browse the validated strategy catalogue. Filter
by ID, provider, deposit mint, source kind, APY type, cluster or APY bounds, with
`page` and `pageSize` for pagination.

## Read rates and capabilities

`rate.value` is an APY decimal fraction: `"0.062"` means 6.2%.
`rate.observedAt` is null when the observation time is unknown. Missing rates
are unknown, not zero.

Check `capabilities.deposit` and its unavailable reason. Discovery coverage can
exceed execution coverage; preparation and execution still check the wallet's
current admission. Provider liquidity, issuer requirements and signing policy
apply independently of the catalogue listing.

Pass the returned `id` as `strategyId` when preparing a deposit. Discovery
covers integrated provider sources; it does not claim every ecosystem strategy.
