A deposit from a customer's wallet is three requests and one signature: pick
a strategy, build the transaction, sign it, submit it. This runs on devnet
with test tokens.

To deposit your organization's own funds instead, use the
[Treasury quickstart](/docs/earn/treasury-quickstart).

## Before you start

| You need | How to get it |
| --- | --- |
| An API key | [Create an account](https://platform.solana.com/sign-up), then [create a key](/docs/developing-with-sdp/manage-api-keys#create-a-key) with Earn **Execute**. Nothing else in SDP needs setup. |
| A test wallet | `solana-keygen new --no-bip39-passphrase -o test-wallet.json` |
| Devnet SOL and USDC | The [Solana faucet](https://faucet.solana.com) and the [Circle faucet](https://faucet.circle.com) on Solana Devnet. The deposit is 10 USDC. |
| Node.js 20.18 or later | It signs the transaction. The cURL examples also use jq. |

In the folder that holds `test-wallet.json`:

```bash title="Terminal"
npm init -y && npm pkg set type=module && npm install @solana/kit@8
export SDP_API_KEY="sf_..."
export WALLET="$(solana-keygen pubkey test-wallet.json)"
```

Then save the file for your language. TypeScript adds each step to
`deposit.ts`; cURL signs with `sign.mjs`.

<Tabs items={["TypeScript", "cURL"]} groupId="earn-code-language">
<Tab value="TypeScript">

```typescript title="deposit.ts"
import { randomUUID } from "node:crypto";
import { readFile } from "node:fs/promises";
import {
  createKeyPairFromBytes,
  getAddressFromPublicKey,
  getBase64EncodedWireTransaction,
  getBase64Encoder,
  getTransactionDecoder,
  partiallySignTransaction,
} from "@solana/kit";

const api = "https://api.solana.com/v1/earn";
const headers = {
  Authorization: `Bearer ${process.env.SDP_API_KEY}`,
  "Content-Type": "application/json",
};

/** Returns the response's `data`, or throws the API's error. */
async function data(response: Response) {
  const body = await response.json();
  if (!response.ok) throw new Error(`${body.error.code}: ${body.error.message}`);
  return body.data;
}

// Sandbox only: a local keypair stands in for your customer's wallet.
const keyPair = await createKeyPairFromBytes(
  new Uint8Array(JSON.parse(await readFile("test-wallet.json", "utf8"))),
);
const ownerAddress = await getAddressFromPublicKey(keyPair.publicKey);
```

</Tab>
<Tab value="cURL">

```javascript title="sign.mjs"
// Sandbox only: signs SDP's base64 transaction with test-wallet.json.
import { readFile } from "node:fs/promises";
import {
  createKeyPairFromBytes,
  getBase64EncodedWireTransaction,
  getBase64Encoder,
  getTransactionDecoder,
  partiallySignTransaction,
} from "@solana/kit";

const keyPair = await createKeyPairFromBytes(
  new Uint8Array(JSON.parse(await readFile("test-wallet.json", "utf8"))),
);
const unsigned = getTransactionDecoder().decode(getBase64Encoder().encode(process.argv[2]));
const signed = await partiallySignTransaction([keyPair], unsigned);
process.stdout.write(getBase64EncodedWireTransaction(signed));
```

</Tab>
</Tabs>

## 1. Pick a strategy

[`GET /v1/earn/strategies`](/docs/reference/api/earn/list-earn-strategies)
lists the strategies your project can see.

<Tabs items={["TypeScript", "cURL"]} groupId="earn-code-language">
<Tab value="TypeScript">

```typescript title="deposit.ts (continued)"
type Strategy = {
  id: string;
  status: string;
  fundable: boolean;
  depositMints: string[];
  depositSlippage: object | null;
};

// Fetch the strategies your project can see.
const { strategies }: { strategies: Strategy[] } = await fetch(
  `${api}/strategies?pageSize=100`,
  { headers },
).then(data);

// Take one that is open for deposits, takes devnet USDC, and needs no slippage floor.
const USDC = "4zMMC9srt5Ri5X14GAgXhaHii3GnPAEERYPJgZJDncDU";
const strategy = strategies.find(
  (s) => s.fundable && s.status === "active" && s.depositSlippage === null
    && s.depositMints[0] === USDC,
);
if (!strategy) throw new Error("No devnet USDC strategy is open for deposits");
```

</Tab>
<Tab value="cURL">

```bash title="Terminal"
# Fetch the strategies, and take one that is open for deposits, takes devnet USDC,
# and needs no slippage floor.
export STRATEGY_ID="$(curl -sS "https://api.solana.com/v1/earn/strategies?pageSize=100" \
  -H "Authorization: Bearer $SDP_API_KEY" | jq -r '
    [.data.strategies[] | select(.fundable and .status == "active" and .depositSlippage == null
      and .depositMints[0] == "4zMMC9srt5Ri5X14GAgXhaHii3GnPAEERYPJgZJDncDU")][0].id')"
echo "$STRATEGY_ID" # "null" means no strategy matched
```

</Tab>
</Tabs>

## 2. Build the deposit

The build returns an unsigned transaction. Nothing moves yet.

<Tabs items={["TypeScript", "cURL"]} groupId="earn-code-language">
<Tab value="TypeScript">

```typescript title="deposit.ts (continued)"
// Build an unsigned deposit of 10 USDC from the wallet.
const { transaction: built } = await fetch(`${api}/external-wallet/deposit-transactions`, {
  method: "POST",
  headers,
  body: JSON.stringify({ strategyId: strategy.id, ownerAddress, amount: "10" }),
}).then(data);
```

</Tab>
<Tab value="cURL">

```bash title="Terminal"
curl -sS https://api.solana.com/v1/earn/external-wallet/deposit-transactions \
  -H "Authorization: Bearer $SDP_API_KEY" \
  -H "Content-Type: application/json" \
  -d @- <<EOF | tee build.json | jq .
{ "strategyId": "$STRATEGY_ID", "ownerAddress": "$WALLET", "amount": "10" }
EOF
```

<Callout type="info">
A `403` with `details.reason` set to `provider_not_entitled` means SDP has not
activated this strategy's provider for your organization yet. Ask your SDP
contact, then build again.

## 3. Sign it

The wallet signs the exact bytes, without changing or broadcasting them.

<Tabs items={["TypeScript", "cURL"]} groupId="earn-code-language">
<Tab value="TypeScript">

```typescript title="deposit.ts (continued)"
// Sign the exact bytes SDP built.
const unsigned = getTransactionDecoder().decode(getBase64Encoder().encode(built.transaction));
const signedTransaction = getBase64EncodedWireTransaction(
  await partiallySignTransaction([keyPair], unsigned),
);
```

</Tab>
<Tab value="cURL">

```bash title="Terminal"
SIGNED="$(node sign.mjs "$(jq -r .data.transaction.transaction build.json)")"
```

</Tab>
</Tabs>

## 4. Submit it

SDP checks the signed transaction against the build, records the deposit, then
broadcasts it. The `Idempotency-Key` header is required.

<Tabs items={["TypeScript", "cURL"]} groupId="earn-code-language">
<Tab value="TypeScript">

```typescript title="deposit.ts (continued)"
// Submit it. Each new deposit takes a new idempotency key.
const { deposit } = await fetch(`${api}/external-wallet/deposits`, {
  method: "POST",
  headers: { ...headers, "Idempotency-Key": randomUUID() },
  body: JSON.stringify({ transactionId: built.transactionId, signedTransaction }),
}).then(data);
```

</Tab>
<Tab value="cURL">

```bash title="Terminal"
curl -sS https://api.solana.com/v1/earn/external-wallet/deposits \
  -H "Authorization: Bearer $SDP_API_KEY" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: $(node -e 'console.log(crypto.randomUUID())')" \
  -d @- <<EOF | tee deposit.json | jq .
{
  "transactionId": "$(jq -r .data.transaction.transactionId build.json)",
  "signedTransaction": "$SIGNED"
}
EOF
```

</Tab>
</Tabs>

## 5. Watch it land

The movement reaches `finalized` within about 30 seconds. Then the wallet
holds a position.

<Tabs items={["TypeScript", "cURL"]} groupId="earn-code-language">
<Tab value="TypeScript">

```typescript title="deposit.ts (continued)"
// Poll until the deposit is final.
let movement;
do {
  await new Promise((resolve) => setTimeout(resolve, 2_000));
  ({ movement } = await fetch(`${api}/external-wallet/movements/${deposit.movementId}`, {
    headers,
  }).then(data));
} while (movement.status !== "finalized" && movement.status !== "failed");

// Read the wallet's positions.
const { positions } = await fetch(
  `${api}/external-wallet/positions?ownerAddress=${ownerAddress}`,
  { headers },
).then(data);
console.log(movement.status, positions);
```

</Tab>
<Tab value="cURL">

```bash title="Terminal"
# Run again until this prints "finalized".
curl -sS "https://api.solana.com/v1/earn/external-wallet/movements/$(jq -r .data.deposit.movementId deposit.json)" \
  -H "Authorization: Bearer $SDP_API_KEY" | jq .data.movement.status

# Read the wallet's positions.
curl -sS "https://api.solana.com/v1/earn/external-wallet/positions?ownerAddress=$WALLET" \
  -H "Authorization: Bearer $SDP_API_KEY" | jq .data.positions
```

</Tab>
</Tabs>
