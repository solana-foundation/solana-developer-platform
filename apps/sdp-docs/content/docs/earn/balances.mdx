---
module: earn
title: Balances and earnings
description: Show each customer's live positions, movement history, and exact earnings, and never show a missing value as zero.
---

Read balances from live positions and history from recorded movements. Each
per-customer read takes that customer's wallet as `ownerAddress`, so your
backend decides which wallet a signed-in customer may see. For custody
wallets, see [Treasury positions](/docs/earn/treasury#read-positions).

| Read | Request | Scope |
| --- | --- | --- |
| Positions | [`GET /v1/earn/external-wallet/positions`](/docs/reference/api/earn/list-earn-external-wallet-positions) | One wallet |
| Movements | [`GET /v1/earn/external-wallet/movements`](/docs/reference/api/earn/list-earn-external-wallet-movements) | One wallet |
| Earnings | [`GET /v1/earn/external-wallet/earnings`](/docs/reference/api/earn/get-earn-external-wallet-earnings) | One wallet |
| Position totals | [`GET /v1/earn/external-wallet/positions/summary`](/docs/reference/api/earn/get-earn-external-wallet-position-summary) | Every wallet in your project |

## Positions

```bash title="Terminal"
curl -sS "https://api.solana.com/v1/earn/external-wallet/positions?ownerAddress=$WALLET" \
  -H "Authorization: Bearer $SDP_API_KEY"
```

```json title="Response (trimmed)"
{
  "data": {
    "ownerAddress": "Af89Mkuvo6AcLDbs7Fxs1FPsnnbD9KrY9NfmaFXHqmPo",
    "positions": [
      {
        "id": "earn_position_2f8b6b04-7147-487e-b760-b1caa4fbcb8b",
        "label": "Kamino Vault USDC",
        "tokenMint": "4zMMC9srt5Ri5X14GAgXhaHii3GnPAEERYPJgZJDncDU",
        "shares": "25",
        "withdrawableShares": "25",
        "tokenValue": "25"
      }
    ],
    "hasMore": false,
    "nextCursor": null
  }
}
```

| Field | Show it as |
| --- | --- |
| `id` | The position ID. Withdrawals name it. |
| `label` | The strategy's display name. |
| `shares` | The wallet's live share balance. |
| `withdrawableShares` | The shares that can leave right now. |
| `tokenValue` | The live value in the deposit token (`tokenMint`). Every Earn deposit token is a USD stablecoin, so at par this reads as dollars. |
| `unlockTimestamp` | When locked shares become withdrawable, in Unix seconds. Null or absent when nothing is locked. |

Positions come newest first, and repeat deposits into one strategy add to the
same position.

- **A missing live value is unavailable.** When the provider read fails,
  `shares`, `withdrawableShares`, and `tokenValue` are left out. Show
  "Unavailable" and disable withdrawals until a read succeeds. Never show zero
  or an old quote.
- **No positions is an empty list,** not `404`. A fully withdrawn position
  drops out.
- **An open withdrawal request holds shares outside the position** until it
  pays out or is canceled. Show its `quotedAssets` as an expected payout.
- **`parIntermediate`** appears while the wallet holds an
  [operator redemption](/docs/earn/withdrawals#asynchronous-withdrawals)'s
  intermediate token outside an open request. It keeps the position open and
  counts toward earnings' `currentValue`.

## Movements

Each deposit and withdrawal is a movement. List a wallet's history, newest
first, or read one by
[its ID](/docs/reference/api/earn/get-earn-external-wallet-movement).

```bash title="Terminal"
curl -sS "https://api.solana.com/v1/earn/external-wallet/movements?ownerAddress=$WALLET" \
  -H "Authorization: Bearer $SDP_API_KEY"
```

```json title="Response (trimmed)"
{
  "data": {
    "ownerAddress": "HM4yQMRMc3gd6TwgraU7r4f4zpJRZmDomzkSPDWmmfi8",
    "movements": [
      {
        "movementId": "earn_movement_a6aed3f5-4f89-4dc6-9d4b-0864021bd80d",
        "direction": "deposit",
        "status": "finalized",
        "settlement": "atomic",
        "amount": "25",
        "denomination": "4zMMC9srt5Ri5X14GAgXhaHii3GnPAEERYPJgZJDncDU",
        "tokenAmount": "25",
        "tokenMint": "4zMMC9srt5Ri5X14GAgXhaHii3GnPAEERYPJgZJDncDU",
        "createdAt": "2026-11-06T18:17:55.220Z",
        "confirmedAt": "2026-11-06T18:17:55.374Z",
        "settledAt": "2026-11-06T18:17:58.425Z"
      }
    ],
    "hasMore": false,
    "nextCursor": null
  }
}
```

Show `tokenAmount` in `tokenMint` units for both directions. On a withdrawal,
`amount` is the share quantity, not the payout, and `tokenAmount` stays null
until SDP observes the payout. Label requested amounts and expected queue
payouts as such. `confirmedAt` is when the network confirmed the movement, and
`settledAt` is when it finalized; see
[How a movement settles](/docs/earn/concepts#how-a-movement-settles).

## Earnings

```bash title="Terminal"
curl -sS "https://api.solana.com/v1/earn/external-wallet/earnings?ownerAddress=$WALLET" \
  -H "Authorization: Bearer $SDP_API_KEY"
```

```json title="Response (trimmed)"
{
  "data": {
    "earnings": {
      "ownerAddress": "HM4yQMRMc3gd6TwgraU7r4f4zpJRZmDomzkSPDWmmfi8",
      "positionCount": 1,
      "unavailablePositionCount": 0,
      "totalsByToken": [
        {
          "tokenMint": "4zMMC9srt5Ri5X14GAgXhaHii3GnPAEERYPJgZJDncDU",
          "currentValue": "25",
          "totalDeposited": "25",
          "totalWithdrawn": "0",
          "earned": "0"
        }
      ]
    }
  }
}
```

`currentValue` is the sum of the positions' `tokenValue`, plus any
intermediate tokens. `earned` is
`currentValue + totalWithdrawn - totalDeposited`, and it appears only when it
is exact. It can be slightly negative right after a deposit, from the
strategy's share rounding. When it is left out, show a dash, never `$0`;
`earnedUnavailableReason` says why:

| Reason | Meaning |
| --- | --- |
| `live_value_unavailable` | A position's live value could not be read. |
| `movements_pending` | A deposit or withdrawal is still settling. |
| `withdrawals_pending` | An open withdrawal request holds shares that have not paid out yet. |
| `deposits_not_valued` | SDP did not observe a finalized deposit's amount. |
| `withdrawals_not_valued` | SDP did not observe a finalized withdrawal's payout. |

- **Only held positions count.** A fully withdrawn position drops out of
  earnings but stays in the movement history.
- **Outside transfers count.** The live value reads the wallet's whole balance
  in the strategy, including shares acquired outside SDP, while deposits and
  withdrawals come only from SDP's records.
- **It is not an accounting ledger.** It gives no lifetime realized returns or
  daily accrual history. Reconcile against your own records for statements.

## Position totals

The summary returns live totals across every customer wallet in your project,
by token and by strategy. It takes no `ownerAddress`.

```bash title="Terminal"
curl -sS https://api.solana.com/v1/earn/external-wallet/positions/summary \
  -H "Authorization: Bearer $SDP_API_KEY"
```

Wallet addresses are personal data, so they are left out unless you pass
`includeOwnerAddresses=true`. Add `includePositions=true` to also get each
wallet's positions; without the address opt-in it returns `400`. Never send
this summary, or your API key, to a customer's browser.

## Paginate every list

| List | Paging |
| --- | --- |
| Strategies | `page` and `pageSize` (default 20, up to 100), until you have `total`. |
| Positions, movements, withdrawal requests | `limit` (default 20, up to 100) and `before`, set to the previous page's `nextCursor`, until `hasMore` is `false`. |

Treat a missing or repeated cursor as an error: a silently short list hides a
customer's money. Earn lists differ from the shared
[Pagination](/docs/reference/conventions/pagination) conventions: the catalog
returns `total`, `page`, and `pageSize` inside `data`, and the cursor lists
take their cursor as `before`.
