Use `GET /v1/earn/positions?ownerAddress=<owner-public-key>` for your wallet's
holdings. No SDP wallet registration is required. An optional `walletId` filter
selects an existing connected wallet instead; `sourceType` distinguishes
`address` and `wallet` sources. Position IDs are the references for withdrawals.

The `ownerAddress` and `walletId` filters are optional; use one, not both.
Without one, the read covers the caller's visible tracked scope.
See [position filters](/docs/reference/api/earn/list-earn-core-positions).

## Discover existing holdings

With one explicit source, `discover=true` reads integrated strategies for
holdings opened outside SDP. The response states coverage and unavailable
strategy counts. Missing provider observations remain unavailable, not zero.
Reads do not import ownership or invent acquisition history.

## Summaries and earnings

`includeSummary=true` aggregates the full selected scope. Owner-address details
require `includeOwnerAddresses=true`; individual positions additionally require
`includePositions=true`.

Respect `costBasisKnown` and `costBasisCoverage`. Display earned yield only when
history and current observations establish it. Keep pending queue shares and
held intermediate tokens visible while settlement is unresolved.

## Activity

Read `GET /v1/operations` with the source filter to recover activity and pending
actions created through the core API. Read an individual operation for its
current next action and result.
