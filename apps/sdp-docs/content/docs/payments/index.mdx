SDP gives you a Solana-native payments stack. It covers stablecoin transfers, fiat onramps and
offramps, and the records you need to reconcile them.

This section follows the structure of the
[public Solana payments documentation](https://solana.com/docs/payments). Each workflow below names
the SDP APIs you call to build it.

Create a custody wallet and a token before you start. See
[Set up wallets](/docs/guides/setup-wallets) and
[Tokenize an asset](/docs/tokens/tokenize-an-asset).

## What is in this section

- **[How payments work on SDP](/docs/payments/concepts)**. Wallets, tokens, signing modes, fees,
  and the transfer data model.
- **Send payments.** The outbound flows.
  - [Basic payment](/docs/payments/send-basic-payment). One transfer, in either signing mode.
  - [Payment with memo](/docs/payments/send-payment-with-memo). Attach an order reference or a
    customer reference to a transfer.
  - [Payouts and disbursements](/docs/payments/send-payouts). Batched outbound transfers, and how
    to reconcile them.
- **Accept payments.** The inbound flows.
  - [Accept payments](/docs/payments/accept-overview). The receiving-address convention and the
    integration options.
  - [Verifying a payment](/docs/payments/accept-verification). What each transfer status means, and
    what finality means.
  - [Indexing and reconciliation](/docs/payments/accept-indexing). List inbound transfers for your
    own ledger.
- **Ramps.** Fiat onramps and offramps.
  - [Ramps](/docs/payments/ramps). Corridor discovery, rate estimates, and the shape of a Ramp
    Quote request.
  - [Ramp providers](/docs/payments/ramps-providers). The capability matrix and the configuration
    for all seven ramp providers.

[Wallet operations](/docs/wallet-operations) documents wallet-wide controls and balances.

## The underlying API

Every page in this section links to endpoints in the generated
[Payments API reference](/docs/reference/api/payments). The Payments API area sits under
`/v1/payments`. It groups into four parts: `transfers`, `ramps`, `wallets/.../balances`, and
`wallets/.../policies`.
