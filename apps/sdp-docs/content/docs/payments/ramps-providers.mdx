SDP currently integrates five ramp providers. They are configured at the organization level via environment variables on the SDP API deployment; the `provider` field on `POST /v1/payments/ramps/onramp/quote` selects between them.

## Sandbox vs production selection

The sandbox/production mode is chosen **per request**, not at deployment time:

- The calling API key's environment picks the mode: sandbox keys (`sk_test_`) use sandbox credentials, production keys (`sk_live_`) use production credentials.
- API keys inherit their environment from their project, and dashboard requests follow the selected project's environment.

Configure both credential pairs for any provider you want to expose to test and live traffic on the same deployment — MoonPay, Lightspark, and BVNK read separate sandbox and production credentials this way. Coinbase and Stripe use a single credential pair regardless of the resolved mode (see their sections below).

## Capability matrix

The public API creates on-ramp quotes only. For off-ramps it offers currency discovery only; the off-ramp column shows which providers `GET /v1/payments/ramps/offramp/currency` lists.

| Provider | On-ramp quote | Off-ramp currency discovery | Sandbox pay-in simulation | Delivery mode | Notes |
| --- | --- | --- | --- | --- | --- |
| MoonPay | ✓ | ✓ | ✗ | `hosted` | On-ramp pairs cover `sol.solana` and `pyusd.solana`. Separate sandbox and production credentials. |
| Lightspark | ✓ | ✓ | ✓ | `manual_instructions` | Grid API. Separate sandbox and production credentials. |
| BVNK | ✓ (USD only) | ✓ | ✓ | `manual_instructions` | Hawk auth. Separate sandbox and production credentials. |
| Coinbase | ✓ (sandbox only) | ✗ | ✗ | `hosted` | Quote creation currently fails; see [Coinbase](#coinbase). |
| Stripe | ✓ | ✗ | ✗ | `session_widget` | `usdc.solana` and `sol.solana` only. No separate sandbox credentials — supply a Stripe test-mode secret key. |

## MoonPay

| Variable | Required | Notes |
| --- | --- | --- |
| `MOONPAY_API_KEY` | conditional | Production API key. Required when the request resolves to production. |
| `MOONPAY_SECRET_KEY` | conditional | Production secret used to sign onramp / offramp URLs. Paired with `MOONPAY_API_KEY`. |
| `MOONPAY_SANDBOX_API_KEY` | conditional | Sandbox API key. Required when the request resolves to sandbox. |
| `MOONPAY_SANDBOX_SECRET_KEY` | conditional | Sandbox secret. Paired with `MOONPAY_SANDBOX_API_KEY`. |
| `MOONPAY_ONRAMP_URL` | no | Override the onramp host. Defaults to MoonPay's standard URLs; the sandbox/production choice follows the [per-request rule](#sandbox-vs-production-selection). |
| `MOONPAY_OFFRAMP_URL` | no | Same idea for offramp. |

You always send canonical asset rails; SDP maps them to MoonPay's currency codes. MoonPay's on-ramp pairs cover `sol.solana` and `pyusd.solana`, so a MoonPay quote for `usdc.solana` is rejected with `UNSUPPORTED_CORRIDOR`. Check [currency discovery](/docs/payments/ramps#discovering-currencies) for the current pairs. MoonPay also rejects on-ramp quotes with a `fiatAmount` below 20.

## Lightspark

| Variable | Required | Notes |
| --- | --- | --- |
| `LIGHTSPARK_GRID_CLIENT_ID` | conditional | Production Grid API client identifier. Required when the request resolves to production. |
| `LIGHTSPARK_GRID_CLIENT_SECRET` | conditional | Production Grid API client secret. |
| `LIGHTSPARK_GRID_SANDBOX_CLIENT_ID` | conditional | Sandbox Grid API client identifier. Required when the request resolves to sandbox. |
| `LIGHTSPARK_GRID_SANDBOX_CLIENT_SECRET` | conditional | Sandbox Grid API client secret. |

Lightspark is integrated against the Grid API (`https://api.lightspark.com/grid/2025-10-13`); the sandbox/production choice follows the [per-request rule](#sandbox-vs-production-selection). `destinationCustodyWalletId` is your own custody wallet, same as every other provider. The counterparty's Lightspark customer is resolved on the server from the counterparty, not passed on the quote request; quoting before the counterparty is provisioned with Lightspark returns `409`. Lightspark's on-ramp pairs cover `USD` to `usdc.solana`.

Lightspark quotes always return `deliveryMode: "manual_instructions"` — the response carries funding instructions to display to the payer, not a redirect URL.

## BVNK

| Variable | Required | Notes |
| --- | --- | --- |
| `BVNK_WALLET_ID` | conditional | Production BVNK-side wallet used for settlement. |
| `BVNK_HAWK_AUTH_ID` | conditional | Production Hawk auth id. Paired with `BVNK_HAWK_SECRET_KEY`. |
| `BVNK_HAWK_SECRET_KEY` | conditional | Production Hawk secret key. |
| `BVNK_SANDBOX_WALLET_ID` | conditional | Sandbox BVNK wallet. Required when the request resolves to sandbox. |
| `BVNK_SANDBOX_HAWK_AUTH_ID` | conditional | Sandbox Hawk auth id. |
| `BVNK_SANDBOX_HAWK_SECRET_KEY` | conditional | Sandbox Hawk secret key. |

BVNK uses Hawk authentication. Bearer-token auth is not currently supported.

BVNK is a travel-rule / compliance-sharing provider: party details come from the counterparty's BVNK customer record, not from the quote request. An on-ramp quote needs a verified BVNK customer with a provisioned funding wallet; otherwise it returns `409`. BVNK on-ramp quotes accept `USD` only.

BVNK quotes always return `deliveryMode: "manual_instructions"` — the response carries funding-account details to display to the payer, including a `paymentReference` the bank transfer must carry.

## Coinbase

| Variable | Required | Notes |
| --- | --- | --- |
| `COINBASE_CDP_API_KEY_ID` | conditional | CDP Secret API Key id. Same key is used for sandbox and production — sandbox is flagged per-request, not by a separate credential. |
| `COINBASE_CDP_API_KEY_SECRET` | conditional | CDP Secret API Key secret. Paired with `COINBASE_CDP_API_KEY_ID`; used to sign a per-request JWT. |

Coinbase is on-ramp only. On-ramp quotes return `deliveryMode: "hosted"`: SDP creates a guest-checkout Apple Pay order and returns its payment link as `hostedUrl`.

Order creation (the quote step) is sandbox-only. Coinbase requires buyer-agreement and phone-verification timestamps that SDP does not collect, so a production request returns `503` instead of sending a false attestation. Coinbase also requires the buyer's email and phone number, which SDP does not pass on the quote, so Coinbase quote creation currently returns `400` in sandbox as well.

## Stripe

| Variable | Required | Notes |
| --- | --- | --- |
| `STRIPE_SECRET_KEY` | conditional | Secret key, sent as the username on HTTP Basic auth. A single key serves both modes — use a `sk_test_…` key to sandbox it, `sk_live_…` for production. |
| `STRIPE_PUBLISHABLE_KEY` | conditional | Publishable key, echoed back on the quote for the client to mount the onramp session. |

Stripe is on-ramp only, limited to `usdc.solana` and `sol.solana` as destination assets. Quotes always return `deliveryMode: "session_widget"`: a `clientSecret`, `publishableKey`, and `sessionId` to mount Stripe's crypto onramp session, plus an optional `redirectUrl`.

## Provider gating

Even when all five providers' env vars are populated, an org can be restricted to a subset. This is [**Provider Availability**](/docs/reference/provider-onboarding): a provider must be configured for the deployment and either generally available or manually activated for the organization. SDP checks this when you create a quote or simulate a sandbox pay-in — if the org lacks availability for the requested provider, the call returns `403`. Currency discovery does not apply this check. To activate or change provider availability for a deployment, see [Provider onboarding](/docs/reference/provider-onboarding).

## Choosing a provider

| Need | Lean towards |
| --- | --- |
| Fastest sandbox iteration | MoonPay or BVNK. |
| Travel-rule / compliance party metadata | BVNK. |
| Lightning-aware fiat settlement | Lightspark. |
| Broadest payment-method coverage | MoonPay (corridor-dependent). |
| Widget/session-embedded onramp UI | Stripe. |

For self-hosted deployments where only a subset of providers will ever be configured, see [Providers optional for self-hosted SDP](/docs/reference/provider-onboarding) — SDP supports running with any single provider active.
