MoonPay is one of SDP's ramp providers, for onramps and offramps. Its capabilities sit beside the others' in the [capability matrix](/docs/payments/ramps-providers#capability-matrix). Quote through [Ramps](/docs/payments/ramps) with `"provider": "moonpay"`.

A Sandbox project uses the `MOONPAY_SANDBOX_*` keys, and a Production project the `MOONPAY_PRODUCTION_*` keys. MoonPay runs in a mode only while all three of that mode's keys are set and fit it. Otherwise it answers `PROVIDER_NOT_CONFIGURED`.

## Configuration

| Variable | Notes |
| --- | --- |
| `MOONPAY_SANDBOX_API_KEY` | Test-mode publishable key (`pk_test_…`). A live key is refused before any request. |
| `MOONPAY_SANDBOX_SECRET_KEY` | Test-mode secret key (`sk_test_…`). It signs the onramp and offramp widget URLs. |
| `MOONPAY_SANDBOX_WEBHOOK_SECRET` | Test-mode webhook key (`wk_test_…`) that signs MoonPay's calls to `/webhooks/payments/ramps/sandbox/moonpay`. |
| `MOONPAY_PRODUCTION_API_KEY` | Live publishable key (`pk_live_…`). A test-mode key is refused before any request. |
| `MOONPAY_PRODUCTION_SECRET_KEY` | Live secret key (`sk_live_…`). |
| `MOONPAY_PRODUCTION_WEBHOOK_SECRET` | Live webhook key (`wk_live_…`) that signs MoonPay's calls to `/webhooks/payments/ramps/production/moonpay`. |

## Behavior

- Quotes return `deliveryMode: "hosted"`: send the customer to `quote.hostedUrl`.
- An offramp quote without `fiatCurrency` pays out in `USD`.
- An offramp quote checks the source wallet's balance first, and refuses a sale the wallet can't fund with `400 INSUFFICIENT_TOKEN_BALANCE`.
- Send SDP's asset rails, such as `usdc.solana`. SDP maps them to MoonPay's currency codes, such as `usdc_sol`.
