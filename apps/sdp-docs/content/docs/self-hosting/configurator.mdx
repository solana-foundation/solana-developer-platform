Use the guided steps below to generate a `.env` file for the default devnet self-hosting path.
Everything runs in your browser. Nothing you enter is sent anywhere.

Put the downloaded file next to `compose.yml`, then run `docker compose up -d`.

For the full operator walkthrough after the download, continue with
[First devnet deployment](/docs/self-hosting/first-devnet-deployment).
