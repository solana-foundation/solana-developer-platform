Self-hosting runs the full Solana Developer Platform on infrastructure you control, from prebuilt
container images. The stack includes the API, the dashboard, the documentation site, a database,
and a cache. You bring your own authentication provider, Solana RPC endpoint, and signing provider.
SDP is the same product you would use as a managed service.

This section covers installing the stack, generating its configuration, and keeping it running.

## Requirements

- A 64-bit Linux or macOS host with **Docker Engine** and **Docker Compose v2**.
- Outbound network access to pull the images and to reach your Solana RPC endpoint and your
  authentication provider.
- A [Clerk](https://clerk.com) application for authentication, and a Solana RPC endpoint. See the
  [environment reference](/docs/self-hosting/env-reference) for the full list.

Use a dedicated endpoint from an RPC provider. The public devnet endpoint
`https://api.devnet.solana.com` rejects `getTokenAccountsByOwner`, so wallet balances do not load
against it.

## Services in the stack

One `compose.yml` file defines the stack. It lives at `infra/self-hosted/compose.yml` in the SDP
repository, and the install script downloads the released copy of that same file into `~/sdp` on
your host.

`compose.yml` starts six services. It pulls each SDP image from the registry in
`SDP_IMAGE_REGISTRY`, at the tag in `SDP_VERSION`. The table shows the default registry, and `<tag>`
stands for the tag you run.

| Service | Image | Purpose |
|---|---|---|
| `sdp-api` | `ghcr.io/solana-foundation/sdp/sdp-api:<tag>` | The core API (default port `8787`). |
| `sdp-web` | `ghcr.io/solana-foundation/sdp/sdp-web:<tag>` | The dashboard web app (default port `3000`). |
| `sdp-docs` | `ghcr.io/solana-foundation/sdp/sdp-docs:<tag>` | The Solana Developer Platform documentation site (default port `3001`). |
| `sdp-migrate` | `ghcr.io/solana-foundation/sdp/sdp-api:<tag>` | Runs database migrations once on startup, then exits. |
| `postgres` | `postgres:16-alpine` | Bundled database (or point at an external one). |
| `redis` | `redis:7-alpine` | Bundled cache (or point at an external one). |
