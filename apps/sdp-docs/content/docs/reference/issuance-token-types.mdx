A **token template** is a fixed composition of Token-2022 extensions for one class of asset. In the
dashboard, the control is labeled **Template**.

`GET /v1/issuance/templates` returns the templates your deployment offers.
`GET /v1/issuance/templates/{templateId}` returns the current definition of one template. Treat the
API as the source of truth for the list and the defaults.

<Callout type="warn">
This page gives general guidance. It is not legal advice. Regulatory treatment depends on the
jurisdiction, and on how the instrument is structured. Confirm your classification before you
deploy a token.
</Callout>

The three templates below cover the common institutional cases:

| Template | Defaults | Notes |
| --- | --- | --- |
| `stablecoin` | 6 decimals, permanent delegate + pausable extensions, default account state initialized | Intended for fiat-backed token patterns with compliance controls. |
| `tokenized-security` | 8 decimals, allowlist on by default and changeable, permanent delegate + pausable + scaled UI amount extensions, default account state frozen | Regulated asset flows with stronger defaults. |
| `custom` | 9 decimals default (up to 18 max), extension set is fully configurable | Use when your requirements do not match the stablecoin or tokenized-security templates. |

Each template also sets the token's **Token Access Control** mode. The mode is `allowlist`,
`blocklist`, or `disabled`. SDP enforces it onchain, over who can hold or receive the token.

Token Access Control is distinct from a wallet's own destination allowlist. The destination
allowlist is a wallet-policy concern.

## Selecting a template

Each template is a vetted, fixed set of Token-2022 extensions for a specific class of asset. It is
not a menu of individual options. Choose the template by the nature of the instrument you issue.
The `custom` template covers an asset that fits neither the stablecoin nor the tokenized-security
model.

### Stablecoin

Use this template for a token that is pegged to a fiat currency and redeemable at par (1:1). It
applies the compliance controls that are typical of a regulated fiat token:

- The **pausable** extension lets you pause transfers for every holder of the token at once. Use it
  in an emergency. This is different from a freeze, which stops one holder's balance.
- The **permanent delegate** lets you seize or claw back tokens in response to a compliance event.

A stablecoin cannot pay interest or yield to its holders. This reflects the payment-stablecoin
frameworks, such as the U.S. GENIUS Act and the EU's MiCA, which prohibit an issuer from paying
interest on the token itself. Issue an interest-bearing or yield-bearing product as a tokenized
security, which is usually a fund, rather than as a stablecoin.

### Tokenized security

Use this template for a regulated instrument, such as equity, debt, or fund shares. It applies the
stablecoin controls together with stronger defaults:

- An **allowlist** is on by default, and you can change that setting.
- New accounts are **frozen by default**, so a holder must be approved before they can transact.
- The **scaled UI amount** extension supports a corporate action, such as a split or a share-class
  rebasing.

An interest-bearing or yield-bearing instrument, such as a debt token or a fund token, also falls
under this template.

### Custom

This template corresponds to the **Non-Security Digital Asset** classification in the issuance
pages. Those assets are neither fiat stablecoins nor regulated securities. Commodities, real
estate, and collectibles are examples.

The template offers the full Token-2022 extension set, including transfer fees, transfer hooks,
non-transferable behavior, and interest. Use it when the stablecoin and tokenized-security
templates do not match the instrument.

### Summary

| Instrument | Template |
| --- | --- |
| Pegged to a fiat currency, redeemable 1:1, with no yield | `stablecoin` |
| Regulated security (equity, debt, or fund), or an instrument that pays a return | `tokenized-security` |
| Any other asset, or one requiring extensions the other templates do not offer | `custom` (Non-Security Digital Asset) |

<Callout type="warn">
SDP sets the Token-2022 extensions when it creates the mint, and nobody can change them afterward.
The template you select is therefore permanent for that token. To change it, issue a new token.
</Callout>

## Amount format

The mint, burn, seize, and force-burn request bodies take `amount` as a **decimal string in UI
units**. That is the human-readable token value, for example `"1"` or `"1.5"`.

SDP converts the value to onchain base units, using the token's `decimals`. Wallet balance
responses differ: they return both a raw `amount` and a `uiAmount`.
