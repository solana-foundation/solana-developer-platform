This section holds the reference material you need to integrate with SDP. Use it after the guides,
when you need an exact endpoint, an exact default, or a downloadable resource.

- [Token templates](/docs/reference/issuance-token-types) explains how to choose a token template
  and what defaults each one applies.
- [Infrastructure provider onboarding](/docs/reference/provider-onboarding) explains how a vendor
  contributes a new provider integration to SDP.
- [Documentation for AI](/docs/reference/docs-for-ai) lists the machine-readable entry points for
  agents and AI systems.
- [Postman collection](/docs/reference/postman-collection) gives you an importable bundle of the
  public API requests.
- [API reference](/docs/reference/api) documents every endpoint in the public API.
