---
title: Postman collection
description: Download the public SDP API Postman collection, generated from the OpenAPI contract.
---

SDP generates the Postman collection from the same public OpenAPI contract that produces the
[API reference](/docs/reference/api). The collection includes every end-user-facing family that the
reference publishes.

SDP excludes the internal-only endpoint families on purpose. Those families are `rpc`, `admin`,
`onboarding`, `auth`, `organizations`, and `members`.

After you import the collection into Postman, set two variables:

- Set `baseUrl` to the SDP API environment you want to target.
- Set `sdpApiKey` to your bearer API key.
