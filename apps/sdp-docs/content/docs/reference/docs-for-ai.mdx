Give your coding agent these entry points. They cover the supported public surface only.

## Machine-readable resources

- [llms.txt](/docs/ai/llms.txt): canonical URLs, supported surfaces, the public endpoint families, and the key pages to start from. The site root serves it too, at `/llms.txt`.
- [llms-full.txt](/docs/ai/llms-full.txt): the full text of every published page, the API reference included, in one file. Also at `/llms-full.txt`.
- Markdown pages: add `.md` to any docs URL (`/docs/reference/docs-for-ai.md`), or request the page with `Accept: text/markdown`. `/docs.md` lists every page. Each page's **Copy page** menu copies the same Markdown.
- [SKILL.md](/SKILL.md): an agent skill with SDP's rules for environments, API key grants, idempotency, and prepare versus execute. The sidebar's **Agent setup** menu has the install command for your agent. The agent-neutral one is `npx skills add solana-foundation/solana-developer-platform --skill sdp-docs`.
- [API reference](/docs/reference/api): every public operation, generated from the public OpenAPI contract.
- [OpenAPI JSON](https://api.solana.com/openapi.json): the public API contract itself.
- [API llms.txt](https://api.solana.com/llms.txt): the API's own discovery file, with its endpoint families and how to authenticate.
- [Postman collection](/docs/reference/postman-collection): the public API as a collection, generated from the same contract.

## Recommended ingestion order

1. Start with [llms.txt](/docs/ai/llms.txt).
2. Load [llms-full.txt](/docs/ai/llms-full.txt) when you need every page.
3. Use the [API reference](/docs/reference/api) and [OpenAPI JSON](https://api.solana.com/openapi.json) for exact request and response schemas.
4. Use the product guides for workflow order, operational limits, and supported patterns.

## Scope

Treat the public docs as the source of truth over internal implementation details. Hidden and internal-only route families are left out of every resource on this page.
